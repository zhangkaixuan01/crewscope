# ADR-041：桌面认证与更新信任链

> 状态：已登记（选入前不生效）<br>
> 日期：2026-10-09（M11-S01 登记）<br>
> 归属：M11-S01 薄登记；选入时在本文件细化，不另建新号<br>
> 关联决策：[ADR-032](ADR-032-实时协作通道与在场模型.md)（实时通道依赖 Web 范围一致）<br>
> 影响里程碑：M11（可选 I03）

## 范围边界（登记时的边界声明）

- **Tauri 只包装既有 Web 产物**：不 fork 业务代码；任何「仅桌面端可用」的业务分支都视为设计失败（M11 红线「桌面端不分叉业务代码」）。
- 交付范围（选入时）：Tauri 壳、本地通知、快捷键、多窗口、深链接与签名更新。
- 不能假设 Web 可直接打包而无认证适配（M11-I03 任务行原文）。

## 已知事实（M11-S01 核实）

- 部署面：四服务拓扑中 web（nginx）是唯一公开端口；`/api/` 反代已配 SSE（buffering off、3600s），当前无 WebSocket Upgrade 透传（I01c 交付项）——桌面壳跟随 Web 能力，不自行开通通道。
- 浏览器认证：Session cookie `CREWSCOPE_SESSION`（httpOnly、SameSite=Lax、Secure 可选）+ CSRF `XSRF-TOKEN` cookie / `X-XSRF-TOKEN` 头 + `SameOriginWebFilter` Origin 一致性校验。桌面 WebView 的 Cookie 存储与 Origin 语义是认证适配的核心风险点。
- 仓库当前零桌面痕迹（无 Tauri/Electron 依赖与配置）。

## 选入后须回答（进入实现前闭合）

1. 加载远程站点还是打包本地 Web 资产（含离线降级语义）（M11 §10.8 开放项 9 的前置）。
2. WebView 的 Cookie/CSRF/同源适配：`CREWSCOPE_SESSION` 在 Tauri WebView 的存储边界、SameSite 行为、与 `SameOriginWebFilter` 的交互。
3. 服务地址发现与切换（本地部署 vs 远程）。
4. 深链接的参数与来源校验、失败回跳路径。
5. 更新信任链：签名更新/回滚机制、平台权限清单；平台签名与镜像 Cosign 不是同一机制（M11-I03 任务行原文）。
6. **I03 是 TASK 还是 FEATURE 的判定**：纯包装且无业务改动 → 降级 TASK 并后置 M11 末尾；需要业务侧适配 → 拆独立工作包重估周期（M11 §9 约定）。

## 结果

登记不产生任何实现义务；未选入时本文不阻塞 M11 主线（含 Web 主线全部验收），也不得被引用为「已验证」。选入后 I03 按本文件细化并在原文件上完成决策，进入实现。
