## 3. 主线冻结详述

### 3.1 组织聚合与归属口径

ADR-035 §2：D01 实体化 Organization 聚合零新增列起步（六列即状态面）；组织创建/管理 API 属托管增量，单机主线 A01 只交付设置/角色/治理；`account_organization_binding` 是唯一绑定底座。矩阵 §6 预勾选托管隔离全部面（129+2 直接覆盖、17 派生 join、3 账号例外、9 平台共享、Redis/对象存储非 SQL 面）。

### 3.2 OIDC 身份与适配（对计划基线的事实修正）

ADR-036 全文：骨架已在（§1 表）；I01 缺口=首登账号开通路径（OIDC 首登建账号/绑定/principal 的语义：受信 issuer+subject 命中或新建，禁止邮箱合并）、身份策略维度（local-only/sso-only/coexist 叠加在 mode 上，默认 coexist、未配 OIDC=M11 完全兼容）、LoginDefense 衔接、救援流程（bootstrap 运维通道或预置救援账号，动作入 Audit）、`/api/v1/auth/sessions` 枚举 API。落点=server/security/oidc+application/identity；零新增依赖。

### 3.3 原子配额

ADR-037 §1–4：挂点/事务/两先例形态/结算对账/上界诚实性全冻结。补充冻结：**受理时无配置配额行=零开销路径**（查询无行即放行，不为每次受理付 advisory 锁成本——锁只在配置存在时介入）；预占拒绝的错误码形态归 A02 契约（PolicyDeniedException 通道，可操作拒绝提示文案归 F02）。

### 3.4 导出/删除/保留协议骨架（细节契约归 A01）

- **导出**：扩 `POST /audit-events/export` 的 bounded JSON 异步先例至全资源导出——授权发起（ORG_ADMIN+）→异步 job 分批产物+manifest 清单（资源类×计数×校验和）→授权拉取；范围覆盖组织作用域全部资源族+M11 WorkGraph 关系表+向量数据；**凭证只导引用不导明文**；导出本身入 Audit。
- **删除**：账号级删除为高危协调操作——先决检查（无在途任务/无未转移责任/无未结预占）→确认（二次确认+原因）→协调清理：主库行（RESTRICT 依赖按绑定链序解除）→派生索引/向量→对象存储工件→凭证吊销；**备份保留策略显式声明**（到期前副本仍存在，不宣称删行即全副本清除）；全流程幂等可重入、每步入 Audit。
- **保留**：audit_event/日志类保留期进组织设置（显式配置，默认=永久）；业务数据不自动过期（永久是默认态，配置了保留期才有滚动清理）；清理作业复用 RuntimeMaintenanceService 模式。
- 组织级删除（整个组织）属**托管增量**，主线不交付。

### 3.5 基础 SLI

ADR-037 §5 六指标口径表冻结；初值目标是 I03 校准前占位（诚实声明，非已验证基线）；容量报告六要素；错误预算烧完触发降级评审（非自动限流）。

### 3.6 ORG_* 角色词汇与 UI 权限

新增第三层词汇（不并入 PlatformRole/TeamRoleKey）：

| 词汇 | 能力 | 不隐式获得 |
| --- | --- | --- |
| ORG_OWNER | ORG_ADMIN 全部+组织级高危（账号删除发起、保留策略、ORG 角色管理兜底）；每组织至少一人（最后一人保护，照 M9b 最后 Owner 先例） | 任何 Team 写权限 |
| ORG_ADMIN | 组织设置读写、ORG 角色分配（除 OWNER）、治理操作（导出/删除协调/保留配置）、审计全读 | Team 写权限；OWNER 兜底操作 |
| ORG_AUDITOR | 组织级审计与用量只读 | 一切写操作 |

正交规则（Release Gate 第 7 条）：Org 角色与 Team 角色独立判定；授权检查先 Team 边界后 Org 补充，Org Admin 不因组织角色通过任何 Team 写路径。初始分配：bootstrap seeder 创建组织时首个账号=ORG_OWNER。UI 权限：session 响应携带组织角色；前端 `auth.ts` 扩 `org:*` 权限词汇（org:manage-settings/org:govern/org:audit-read），F01/F02 按此渲染；无 ORG_* 分配时设置页只读态（仅 ORG_OWNER 可见角色管理入口）。

### 3.7 前端形态裁定（S01 必答）

- **趋势图表基元：手写 SVG**（`web/src/components/charts/` 新建，折线+柱状两形态起步）。理由：①趋势图形态简单（时间序列两形态），WorkGraph 已证明手写 SVG 可达完整 a11y（键盘/焦点/sr-only）；②引入图表库违反「不要这样做」17 条的评估前置要求且为两形态引入整库；③Reduced Motion/axe 全自控。规模上界：超出 ~200 数据点降级为表格（大图降级先例）。
- **`/settings/quota` 裁定为独立子页**（SettingsShell 导航新增「配额与用量」区块，与「组织」区块并列）：配额域（domains/quota 四件套）与组织域职责分离，避免 organization 区块同时挂治理+配额两个 store；两页共享 ORG 权限词汇。
- **SLI 摘要归 `/observability` 页扩展**（`domains/observability` 扩展，不新建页面）：SLI 是观测只读面，与成本质量页同域；配额页是治理动作面，两者不混。
- 组织名收敛：identity store L224 硬编码占位串删除，组织名从组织域 store 单源（A01 组织设置 API 返回）。
- F03 会话管理：AccountPage `#sessions` 扩为列表+单撤销（数据面=§必答 9 端点）；身份源策略提示挂 LoginPage（registrationMode 提示先例）。
- **OIDC 攻击集 IdP 形态（§10.7「S01 冻结」项）**：Q01 端到端攻击集默认用 gate 独立 Compose 栈**内置容器化 IdP**（Keycloak 或 Dex，Q01 按镜像体积/配置面选型）走真实协议（签名/issuer/audience/state/nonce/PKCE 全链真实），不用 mock stub 冒充；I01 单测层允许 stub；外部托管 IdP（Auth0 等）如需联测属「需授权或环境」枚举。
