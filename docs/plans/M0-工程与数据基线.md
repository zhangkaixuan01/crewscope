# M0：工程与数据基线执行清单

> 对应总计划：[CrewScope 实施计划](../CrewScope-实施计划.md) M0<br>
> 目标周期：2–3 周<br>
> 目标结果：真实 PostgreSQL 仓储、事件投影基线、存储 Port、AgentScope 技术验证和稳定 CI<br>
> 当前进度：全部任务已完成（2026-08-07），M0 Release Gate 已通过，下一项为 `M1-D01`

## 1. 出口结果

M0 完成后具备：

- PostgreSQL/Redis Testcontainers 测试基线；
- V1 到 V5 的空库和升级迁移；
- WorkItem 真实 PostgreSQL Repository；
- DomainEvent、Outbox、Publisher、Audit 和 ProjectionCheckpoint 最小闭环；
- ArtifactStore 与 CredentialStore 可用实现；
- AgentScope Harness、Structured Output、AG-UI Resume 和 Docker Sandbox 可复现验证；
- 统一 API、日志、Trace、前端和 CI 基线。

## 8. M0 验收场景

1. 空 PostgreSQL 执行 V1、V2、V3、V4、V5，应用启动成功；
2. 创建 WorkItem 后，业务事实、DomainEvent 和 Outbox 同时提交；
3. Publisher 重复投递，Audit 与 Checkpoint 保持幂等；
4. FilesystemArtifactStore 写入、校验、读取、过期和清理成功；
5. CredentialSecret 只出现密文，错误主密钥无法解密；
6. HarnessAgent 完成 Structured Output 和 AG-UI 中断恢复；
7. Docker Sandbox 修改临时仓库，宿主 Diff Watcher 观察到一致变更；
8. AppShell 可在 Conversation/Control 入口间切换，Token、Focus、响应式和基础错误状态符合前端规范；
9. 后端验证和前端构建在 CI 干净环境通过。
