## 1. 用户现在怎样使用

**Inbox 收纳可逆（契约 §5.1 七行状态表全量落地）**：UNREAD/READ/ACTED/ARCHIVED 四态按显式矩阵转换——归档可恢复（恢复回到已读，不假装精确恢复历史）、READ/ACTED 可重新标未读（持久 UNREAD 行，不删 authority 行）、归档内标未读走显式「恢复并标为未读」两步（同事务 ARCHIVED→READ→UNREAD，复用单幂等键）、重放相同命令返回原回执。无行=UNREAD 语义（`COALESCE(status,'UNREAD')='UNREAD'` 计数口径）。批量条支持归档/标已处理，逐项呈现成功/拒绝/冲突/未知四类结果，「未知」项给「先确认结果」入口而不盲目重试；`?disposition=ARCHIVED` 归档视图入口进路由白名单。

**搜索与选人各自信任自己的会话**：命令面板与搜索页各持一个 SearchStore 实例（`SEARCH_STORE` / `PALETTE_SEARCH_STORE`），面板打开/清空不再清空搜索页结果；搜索页失败态保留上次结果并排显示「仍显示上次结果」，重试重发**已提交**条件而非草稿。PrincipalPicker 续页（`after` cursor）、已选 chip 点击重开更换、停用/重名组合呈现、切 Scope 清旧候选、Enter 带 IME 守卫。

**个人视图与固定项目（R41）**：`savedViews.ts` 把 F05 冻结的 view/pin 存储合同接成功能——命名保存/更新/删除个人筛选视图（work/today 各自白名单键序列化）；应用优先级「显式 URL > 已保存默认视图 > 页面默认」，且只在 URL 无筛选键时套用并 replace，旧偏好永不覆盖分享链接；固定项目/工作排序，名称经当前授权查询后显示，撤权后显示不可见占位（不显示旧标题）；「本机存储，不跨设备同步」常驻说明；保存视图注册进 CommandPalette 动作。

**审计查人不再 UUID（R33/R34）**：initiator/actor/agent 三字段换 PrincipalPicker（purpose=AUDIT，含历史身份）；导出只认已应用条件——表单与已应用不一致即禁导出并给「应用筛选」入口，范围摘要常显，成功显示实际条数与「可能不完整」提示（`events.length >= maximumRows` 前端近似）；行复选框与无用途 useSelection 移除；新增后端 `GET /audit-events/{eventId}` 定点详情（AUDIT_READ + AuditAccessRecord），`?auditEvent=` 深链在新窗口/刷新直达。

**观测恢复三态分明（R38）**：首次失败（无 invocationId）给「重新生成摘要」+「检查配置」（纯导航不带草稿文本）；完成态「重读本次结果」（GET summary 回读）与「按最新重新生成」（新 invocation）明确分离，成本说明常驻；单条证据失败就地 `role="alert"` + 该条重试，不再升级成全局失败。

## 4. 固定反例与实施偏差（每个都曾真实失败或推翻计划）

**S7 基线容差谜题**
- `maxDiffPixelRatio: 0.02`（playwright.config.ts:31）在宽视口消化真实差异：desktop 1440px 宽 +20px 折行 ≈ 2.9 万像素差落在 43.2k 容差内**假绿**，narrow 390px 同差异超 12.9k 容差才暴露。结论：**desktop「通过」不能当作「无变化」的证据**，触碰组按归属重拍不靠容差侥幸。

**S10 时间与行盒**
- **RelativeTime display:inline 决定**：块级化会撑高宿主行（audit 行 +4px），组件根 `display:inline` 保持原文本流行盒；仅此仍留下 -1/-2px 级差异（见下）。

- **fullPage 拼接缝/fixed 相位差机制**：m6-inbox narrow 总高 1912→1911（-1px）与 control narrow -2px，正文逐字一致、纯平移——Chromium fullPage 截图按视口滚动拼接，**fixed/sticky 元素（状态栏/底栏）每屏重复捕获**，总高 1px 差改变滚动序列 → 每条拼接缝相位差 + fixed 元素与内容相对位置变化，被像素比较放大成多带差异；低对比度全区域差异则是拼接边界光栅化噪声。判定为预期排版微变、内容零变化，重拍收口。
- **RelativeTime 替换 18 处而非计划 9 处**：实际盘点全站内联 `formatRelativeTime`（InboxWorkspace/AuditExplorer/ActivityStream/WorkItemCard/WorkDeskBoardCard/Operations/Search/Conversation×多行/Today×5/ProjectExecutionDefaultsPanel），逐处替换并回归。
