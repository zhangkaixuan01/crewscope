## 390px 菜单可达性（移动端触达）

新增 `--cs-touch-min: 44px` Token，作为所有交互控件的最小命中区域下限。密度体系是「基准档减若干像素」派生出更紧凑的档位（例如 `small` 变体是基准高度 −4px），因此下限必须套在**派生后最小的那一档**上而不是基准档上——否则 `small` 变体会在数值上滑到 44px 以下，Token 名义上生效但实际防不住最小的那个控件。

新增 `e2e/menu-walk.ts` 共享夹具（同一份 `MENUS`/`mockApi()` 也被 `m9-dark-theme.spec.ts` 复用），对未 mock 的 GET 请求返回形状合法的空结果（列表类路径给 `{items:[], nextCursor:null}`），让页面渲染真实空状态（工具栏、筛选器、主操作仍然显示），而不是卡在 loading。

`e2e/m9-mobile-reach.spec.ts` 在 390px 视口下逐个走查全部 14 个菜单：

1. 舒适密度与紧凑密度下，所有可交互控件的命中区域 ≥ 44px，且没有横向溢出；
2. 折叠导航（抽屉收起）状态下，每个菜单仍可通过展开抽屉到达——排除了用 `display: none` 隐藏导航却没有替代入口的写法。

```text
pnpm exec playwright test e2e/m9-mobile-reach.spec.ts   PASS (2 tests × 14 菜单)
```

抽屉键盘焦点陷阱、Esc 关闭、遮罩关闭和焦点归还已由 `e2e/m9-mobile-reach.spec.ts` 的移动导航用例覆盖，`scripts/check-dialog-focus.mjs` 负责补充生产 modal 的静态键盘契约检查。
