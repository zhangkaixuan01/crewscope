# M9-F11 全站菜单体验对齐验证

## 交付范围

- AppShell 在 767px 以下提供移动端抽屉导航，支持键盘焦点陷阱、Esc 关闭、遮罩关闭和焦点归还；页面主操作保留在页眉动作槽。
- 路由声明唯一 `meta.title`，导航当前项使用 `aria-current="page"`，根路径和 onboarding 完成态进入个人工作台。
- Team Observer、404、无权访问页覆盖加载、错误、空状态及下一步行动出口。
- Activity 筛选、实时流和续页使用同一服务端筛选；Inbox 增加“全部”视图；成员页显示角色与中文状态并隐藏内部版本号。
- Operations 轮询受页面可见性保护；Audit 导出为 UTF-8 CSV，字段按 RFC 4180 规则转义。
