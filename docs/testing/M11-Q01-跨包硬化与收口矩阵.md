## 3. 归属裁定与书面结论

1. **查询侧越权无泄漏的检验法**：外队成员查存在与不存在的 anchor 异常同型（PolicyDenied 先于 anchor 查找）；跨队 item 与不存在 id 均 AggregateNotFound 且 details.aggregateType=WorkItem——比计划文字更精确且不违反合同。
2. **「掉线期间积压事件恢复后补 sweep」口径**：at-least-once 重投已由 D02 redelivery 断言承证；Redis 容器无持久化恢复=积压清零，Q01 断言「不复活」（恢复后重登录重订阅仍 forbidden_scope），不虚报「补投」覆盖。
3. **SSE 端点错误体形态**：Accept: text/event-stream 协商下 403 的 JSON envelope 由 SSE writer 编为 `data:{...}` 行——断言取 raw body 包含 policy_denied 且无事件泄漏，不用 JSON path。
4. **Docker Desktop 随机端口漂移（环境事实登记）**：随机发布端口在容器 stop→start 后被重分配（实证 59300→59301），固定绑定端口回绑正常——Redis 断供注入的容器必须固定 host 端口，否则恢复断言必假败。
5. **SUSPENDED 与 REMOVED 同分支**：两态均归 `canParticipate()==false`（status!=ACTIVE），一个中途 SUSPENDED 场景即覆盖（HandoverTargetRevocationM11Q01IntegrationTest javadoc 注明）。
6. **真实栈 Redis 演练的降级预案未触发（终跑 2026-10-12）**：session 连坐（误登出）未发生——Lettuce 重连先于 session 失效窗口；预案（裸 WS 观察形态）保留在 spec 注释与计划中，若未来栈形态变化再启用，不静默改判。
