## 3. 归属裁定与书面结论

1. **注入清单 TTL（回填主计划 §10.11 第 7 条）**：维持 I02c 冻结——清单/反馈/回执无 TTL、无主动清理，随 `task_execution` 的 `ON DELETE RESTRICT` 生存期存续；Q01 不引入清理作业，主动清理策略（按月归档/删除等）留 M12。主计划 §10.11 第 7 条括注已同步改为本裁定。
2. **e2e 计划名映射**：主计划与评审语境中的「m10-feature-flags-off」前端组合验证，落地为真实栈 spec crewscope-web/e2e/m10-real/feature-flags-off-real-api.spec.ts；无独立 mock spec——全关合同的每条断言（enqueued:0、422 skill_disabled、RETRIEVAL_DISABLED 降级、空观测结构）都是真实栈行为，mock 档无法承证。
3. **A01 mjs 评测 gate 对运行栈真实执行**：需 DashScope key+运行中的增强栈，本包环境不可达——登记「需授权或环境」（与 q01/S10 同因、同批复跑）；真实执行随 Q02 真实模型闭环一并补证。
