# M9-F05 状态动作体验验证

## 验收范围

- WorkItem 详情使用动词化动作按钮（如“开始执行”“提交评审”），不再使用目标状态下拉框。
- 主动作使用 Primary，其余动作使用 Secondary；取消与归档要求再次点击确认。
- Review 结论使用分级按钮：留言为弱动作、通过为正常动作、请求修改为警示动作、拒绝为危险动作并二次确认；历史记录展示中文语义。
- 所有动作继续调用现有状态机与 ETag 命令路径，前端仅消费生成的可用目标，不改变领域状态边和事件 Schema。

## 本地验证

```bash
pnpm --dir crewscope-web exec vitest run src/components/domain/WorkItemDetailDrawer.spec.ts src/components/domain/ReviewWorkbench.spec.ts
pnpm --dir crewscope-web build
```

使用键盘验证动作按钮的聚焦、执行、危险动作确认和服务端冲突提示；在离线、无权限、版本冲突场景确认动作被拒绝且保留当前详情。
