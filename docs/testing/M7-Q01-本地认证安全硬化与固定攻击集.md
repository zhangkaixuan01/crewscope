# M7-Q01 本地认证安全硬化与固定攻击集

> 任务：`M7-Q01`<br>
> 状态：已完成<br>
> 日期：2026-08-29<br>
> 范围：密码、登录防护、账号枚举、Session、CSRF、Cookie、Origin、安全返回目标、日志与公开响应

## 1. 交付结果

M7-Q01 将 CrewScope 本地认证边界固化为一键执行的版本化安全门禁。固定攻击集使用稳定编号并自校验精确分母；任意样本减少、重复、改号或由拒绝变为接受都会使门禁失败。真实 Redis 与真实 HTTP 回归同时证明 Session 轮换、续期、并发上限、过期、退出、全部设备撤销以及合法登录不受攻击防护影响。

统一入口：

```bash
./scripts/m7-q01-security-gate.sh
```

脚本要求 Docker、Node.js 24+ 和 pnpm 可用。Docker 是强制前置条件，避免真实 Redis Session、限流原子性和密码安全集成测试被静默跳过。

## 2. 固定攻击分母

| 分组 | 编号 | 数量 | 攻击面 | 阻断合同 |
|---|---:|---:|---|---|
| 密码预算与弱密码 | `PW-01`–`PW-16` | 16 | 空值、过短、常见密码、大小写绕过、超 Code Point、超 UTF-8 Byte、非法 Unicode | 注册拒绝弱输入；登录在昂贵 Hash 前拒绝不安全上限 |
| 暴力尝试预算 | `BF-01`–`BF-12` | 12 | 标识、受控网络与已知账号计数越界、负数与极大计数 | 固定阈值关闭，非法计数失败关闭 |
| 账号枚举 | `EN-01`–`EN-12` | 12 | 用户名、邮箱、未知/锁定/禁用/Operator 形态、Unicode、SQL/路径探针 | 统一 `401 invalid_credentials`，无状态差异和提交值回显 |
| CSRF 混淆 | `CS-01`–`CS-10` | 10 | 缺失、单边、错配、重复、合并、编码、空白和超长 Token | 统一 `403 csrf_rejected`，不进入 Controller |
| Origin 绕过 | `OR-01`–`OR-16` | 16 | 跨站、null、非法 Scheme、协议相对、端口、UserInfo、Path/Query/Fragment、Host 后缀、多值 | 统一 `403 cross_origin_rejected`，无 CORS 凭证响应头 |
| Session 状态注入 | `SS-01`–`SS-14` | 14 | 空 Principal、非法 Security Version、非白名单序列化类型、TTL/上限/Namespace 降级 | 只接受最小无凭证 Principal 与受控 Redis Session 形状 |
| Cookie 降级 | `CK-01`–`CK-08` | 8 | Name、Path、HttpOnly、SameSite、HTTPS Secure、本地传输 Secure 和缺失值 | Team Beta 启动前拒绝偏离固定 Cookie 策略的配置 |
| 日志与响应泄漏 | `LK-01`–`LK-16` | 16 | 公开 DTO 字段、密码、登录标识、Session、Cookie、Authorization、Ciphertext、异常消息 | 公开形状无凭证坐标，结构化日志固定脱敏，异常正文不透传 |
| 开放重定向 | `RD-01`–`RD-24` | 24 | 绝对/协议相对 URL、反斜杠、Fragment、身份/未知路由、危险 Scheme、控制字符、超长和多值 | 只恢复已注册受保护站内路由，其他目标回到 Conversation |
| 合计 |  | **128** |  | **128 / 128 阻断** |

固定分母由 Java `104` 个动态攻击样本与 Web `24` 个安全返回目标样本组成。分母自校验用例不计入攻击数量。

## 3. 行为安全回归

固定攻击之外，一键门禁继续执行以下生产行为：

- Argon2id M32/T3/P1、Dummy Hash、旧 Hash 升级、Credential CAS 与有界 Hash Permit；
- Redis 标识/网络窗口、账号临时锁定、并发原子预算、HMAC 资源隔离、Redis 故障失败关闭；
- 登录前后 Session ID 轮换，窃取登录前 Session 不能获得认证态；
- 两个浏览器 Session 隔离、Redis 续期、过期、最大 Session 数、当前设备退出和全部设备撤销；
- Local 模式 CSRF、同源 Origin、公开/受保护路由、业务 API 零 Basic Challenge；
- 账号不存在、密码错误、禁用、锁定和损坏 Credential 的统一昂贵匹配与公开错误；
- Session Cookie 固定为 `CREWSCOPE_SESSION / HttpOnly / Path=/ / SameSite=Lax`，HTTPS 必须 `Secure`；
- 登录、Session、账号和邀请公开 DTO 不含 Password、Hash、Session ID、Cookie 或长期 Token；
- Web 身份 Gateway、AuthStore 与 API Client 不持久化密码、CSRF、Session 或 Principal 私有坐标。
