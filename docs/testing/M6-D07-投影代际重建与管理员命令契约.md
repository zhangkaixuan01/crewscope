## 2. Definition、Generation 与 Pointer

`ProjectionDefinition` 固定以下执行坐标：

```text
ProjectionName
DefinitionVersion
ProjectionSchemaVersion
CanonicalEncoder
Validator
```

Generation 使用 `OrganizationId + ProjectionName + ProjectionGeneration` 完整定位。Registry 快照必须包含一个由 Pointer 精确指向的 `ACTIVE` Generation，启动或重试时不能存在 `BUILDING/VALIDATING` 影子代际。新代际始终使用已存在最大代际的下一值。

`ProjectionPointer` 是当前读代际的唯一来源，切换携带 Pointer、旧 ACTIVE、目标 VALIDATING 和 RebuildJob 四个强版本。Infrastructure Adapter 按 Pointer、目标 Generation、旧 ACTIVE、Job 的固定顺序加锁并在一个事务提交四项更新。

## 3. 校验、切换与 Fencing

每次校验保存：

```text
DefinitionVersion + Generation + RebuildJobId
Expected Count + Expected Canonical SHA-256
Actual Count + Actual Canonical SHA-256
Gap Count + Hashed Failed Partitions + Bounded Failure Code
ValidatedBy + ValidatedAt
```

Count/Hash 完全相等、Expected/Actual 均无 Gap 且无失败分区时进入 `VALIDATING`。失败校验保留诊断结果并保持当前影子状态。VALIDATING 接收到新事件后，切换事务重新计算的快照与已保存快照不同，切换失败并要求再次校验。

校验、激活、退役、失败和取消均提升 Fencing Token。Worker 在写 Receipt、Checkpoint 和投影行的同一事务中调用 `requireWritableBy`，Generation、状态或 Token 任一不匹配时拒绝写入。终态不能签发新 Lease，也不能恢复或原地重试。

## 4. 取消、失败与重试

`BUILDING/VALIDATING` 可以进入 `FAILED/CANCELLED`。Generation 与 RebuildJob 同时终结并保留历史。重试只接受同一 Organization/Projection 下的 `FAILED/CANCELLED` Job，创建新的 RebuildJobId、新 Generation 和初始 Fencing Token；原 Job、ValidationResult、Generation 和诊断信息保持不变。

Checkpoint 引用必须闭合完整 Generation Key 与 Partition Key。Dead Letter 引用只包含完整 Generation Key、DeadLetterId、Partition Hash 和有界 FailureCode，不保存原始 Partition、Payload 或异常文本。

## 5. 管理员命令与安全事件

`ProjectionAdministrationService` 的启动、重试、校验、切换、取消和失败命令统一执行：

1. 使用 Server 从当前认证解析的 `TeamAccessContext` 复验 ACTIVE USER、Organization Scope 与可信平台管理员事实；
2. 与 Action、Projection、目标 Generation 精确绑定的强确认短语；
3. Organization 内唯一 Command ID 与安全坐标 SHA-256 请求指纹；
4. Definition、Pointer、Generation 和 RebuildJob 强版本检查；
5. Repository 原子保存状态变更、Command Receipt、DomainEvent 和 `PROJECTION` Audit；
6. 相同 Command ID/相同指纹返回原 Receipt，不同指纹返回幂等冲突。

`ProjectionLifecycleEvent` 只公开 Command、Organization、Projection、Definition Version、Generation、RebuildJob、低基数 EventType/Status、Actor、时间、旧代际编号和有界 FailureCode。事件形状不包含 Payload、Secret、Credential、Endpoint、原始分区或异常文本。
