# M1-D08：M1 持久化适配

> 日期：2026-08-08<br>
> 状态：已完成<br>
> 模块：`crewscope-application`、`crewscope-infrastructure`

## 目标

实现 M1 领域对象到 V6 数据模型的完整持久化适配，闭合 Team 初始化、默认 Personal Agent、WorkProject、WorkItem、Comment、ResourceLink 和 ResponsibilityAssignment 应用 Port。所有租户查询显式携带 Organization，团队与工作对象写入携带完整 Scope。

## 持久化范围

### Team 基础

实现：

- `TeamRepository`；
- `WorkspaceRepository`；
- `TeamMemberRepository` 与 `TeamMembershipQuery`；
- `TeamRoleRepository`；
- `MemberRoleRepository`；
- `AgentProfileRepository`；
- `DefaultPersonalAgentRepository`。

Team 初始化保持一个 REQUIRED 事务：

```text
Team
-> Workspace
-> Owner TeamMember
-> Built-in TeamRoles
-> Owner MemberRole
-> Personal Agent Principal + AgentProfile
-> COMMIT 校验 Team 延后外键
```

默认 Personal Agent 初始化先锁定 TeamMember 行，使用数据库当前状态校验成员仍为 ACTIVE，且当前 USER Principal 与候选 Personal Agent Owner 一致，再查询 active 默认 Profile。不存在时原子插入稳定 ID 的 Principal 与 AgentProfile，已存在时返回完整现有对象。Principal 与 Profile 不允许部分提交。

V6 合法保留的未初始化 V5 Team 缺少 Owner 与默认 Workspace。Team Mapper 将该状态转换为带 Team ID 的 `TeamInitializationRequiredException`，避免空值异常掩盖待补全语义；M1-A01 提供产品化查询与补全入口。

### Work 管理

实现：

- `WorkProjectRepository`；
- 完整 M1 `WorkItemRepository`；
- `WorkItemCommentRepository`；
- `WorkItemResourceLinkRepository`。

WorkItem Mapper 保存并恢复 Type、Description、Priority、Labels、DueAt、Source、SourceReference、Version 和 AuditMetadata。列表继续使用 `updated_at + id` 降序 Keyset Cursor。Comment 和 ResourceLink 是不可变事实，只提供创建、按 ID 查询和按 WorkItem 查询。

### 责任

`ResponsibilityAssignmentRepository` 实现：

- `lockResponsibilityChain`；
- 创建与版本更新；
- 按 ID 查询；
- 查询 active Owner；
- 查询 WorkItem active 责任链；
- 查询指定 Role/Actor active Assignment。

`lockResponsibilityChain` 使用只读取稳定 ID 的原生锁语句，不加载 Description、Labels 或其他 WorkItem Entity 状态：

```sql
SELECT id
FROM crewscope.work_item
WHERE organization_id = ? AND id = ?
FOR UPDATE
```

Owner、Executor 和 Reviewer 变更在同一 WorkItem 行锁后读取责任链并执行策略。Assignment 更新使用旧 Version 谓词。部分唯一索引冲突映射为稳定责任冲突，版本不匹配映射为 `OptimisticLockConflictException`。

## Entity 与 Mapper 规则

- Entity 只保存标量 ID，不使用隐式 ORM 关系跨越租户边界；
- Mapper 显式构造强类型 ID、枚举、Optional、UTC 时间和 Audit/Lifecycle Metadata；
- TeamRole Permissions 与 WorkItem Labels 使用 JSONB 集合；
- 新聚合创建要求 Version 为 0；
- Domain 变更后的 Version 必须等于数据库旧 Version 加 1；
- Workspace 更新同时匹配 Organization、Team/Personal Scope 与 ID；
- AgentProfile 更新同时匹配 Organization、Team、Workspace 与 ID；
- 更新语句同时提交状态、`updated_at`、`updated_by_principal_id` 和 Version；
- 更新影响行数为 0 时，先区分不可见/不存在与真实版本冲突；
- 读取始终包含 Organization 谓词，Scope 不匹配不返回对象；
- 不使用数据库自动更新时间语义。

## Repository Port

M1 Port 提供面向领域生命周期的 Create、Read、Update 和 List。业务对象使用 Archive、Release、Revoke 等状态迁移，不提供物理 Delete。分页使用稳定 Keyset Cursor，不使用 Offset。
