# M9-A05：WorkItem 动作可用性验证

## 交付内容

- `WorkItemTransitionCatalog` 复用 `WorkItem` 的权威状态机边集合，仅补充动作标签、强弱级别和可撤销标记。
- `WorkItemTransitionAvailabilityQueryService` 复用 `WorkItemAccessPolicy` 的可见性与 `WORK_PARTICIPATE` 权限判定。
- 新增查询端点：
  `GET /api/v1/organizations/{organizationId}/teams/{teamId}/work-projects/{projectId}/work-items/{workItemId}/transitions/availability`
- 不可用动作保留在响应中，并返回稳定 `reason`；当前已接入状态机、权限和外部 Provider 三类原因，其余冻结枚举等待 Review/Gate 事实接入。

## 本地验证

```bash
./mvnw -q -pl crewscope-domain,crewscope-application,crewscope-server -am -DskipTests compile
./mvnw -q -pl crewscope-domain,crewscope-application,crewscope-server -am \
  -Dsurefire.failIfNoSpecifiedTests=false \
  -Dtest=WorkItemTransitionCatalogTest,WorkItemTransitionAvailabilityQueryServiceTest,WorkItemTransitionControllerTest test
node scripts/generate-state-machine.mjs
node scripts/check-openapi-drift.mjs
git diff --check
```

测试覆盖状态机边集合对账、原生/外部 WorkItem、权限不足、非法标识符和安全缓存策略。动作可用性仅用于前端发现，实际状态转移仍由命令服务独立执行完整校验。
