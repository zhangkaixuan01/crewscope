# M9b-A03 模型连接健康与重新启用完成

日期：2026-09-23  
状态：已完成实现与定向自动化验证（未提交/推送）

## 交付内容

- 连接领域允许 `SUSPENDED` 连接执行健康验证；`REVOKED` 仍不可验证、不可恢复。
- 新增应用/API `POST .../model-connections/{connectionId}/activate`，复用 owner 权限、`If-Match`、Credential Version 与 Idempotency-Key。
- 重新启用只接受 Provider ACTIVE 且当前凭据健康为 `HEALTHY` 的连接；健康未知、不健康、凭据不可用或 Provider 停用均拒绝。
- 新增 `MODEL_CONNECTION_ACTIVATED` 审计事件；命令回执和审计摘要不携带凭据或 Provider 原始响应。
- 设置页接入“重新启用”按钮：停用连接显示恢复说明，只有健康状态为“健康”时启用；轮换凭据后要求再次验证。
- 健康探测 HTTP 客户端显式禁止重定向，响应体丢弃，Bearer 只在一次探测调用内存在。
- OpenAPI 生成物已更新，包含 activate 操作；漂移检查基线更新为 220 个操作。
