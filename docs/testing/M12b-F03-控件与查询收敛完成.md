## 2. 基础件合同（base 层，3 文件 + 1 删除）

- **BaseMenu（新建）**——全站唯一下拉原语。`v-model:open`（状态归消费者）+ `kind: 'menu' | 'listbox'` + `placement` 四角 + `label/triggerLabel/triggerClass/menuClass/initialFocus/rovingFromEditable`。键盘合同（此前 6 套各自为政，现在一份）：
  - 打开即聚焦首个可用条目（跳过 `aria-disabled` 与 `:disabled`）；触发钮 ArrowDown/ArrowUp 也能开（首项/末项）；
  - ArrowUp/Down 循环、Home/End 跳首尾；**Escape 在 document 捕获阶段单点仲裁**（preventDefault + stopPropagation + 关闭 + 还焦触发钮——焦点在弹层外也要关）；
  - Tab 从条目上关闭不拦截；editable target（input/textarea/contenteditable）上方向键/Home/End 让渡文本编辑（`rovingFromEditable` 可选收回，ModelOptionPicker 用）；
  - 弹层外 pointerdown 关闭不动焦点；程序化关闭（v-model false）若焦点原在弹层内 → nextTick 还焦触发钮，带**模态守卫**（页面存在 `[role="dialog"][aria-modal="true"]` 时不抢——F02 MemberActionMenu 竞态修复的泛化）+ `trigger.isConnected` 守卫；
  - 弹层不 teleport：保住消费者 `:deep()` 几何定制路径（ScopeSwitcher 断点 fixed、UserAccountMenu popover 覆盖）。`<Transition name="cs-pop">` 进出场消费 F01/F02 的 ease token。
  - spec 13 条全绿（宿主组件闭环 v-model；每条断言对应迁移前至少一套实现做不到的事）。
- **BaseSelect（升级）**——内层原生 `v-model` 读 option 的**绑定值**（`el._value`）而非 DOM 字符串：数字选项（TeamInvitationManager 分钟数）、`null`「不设置」选项（ProjectExecutionDefaultsPanel）、slot `:value` 原始类型与迁移前完全一致。`modelValue: string | number | null`。新增 `defineExpose({ focus })`——模板 ref 从元素变组件后命令式 API 不断（RepositorySettingsPage 打开面板即聚焦 select 的合同由其 spec 承证）。
- **BaseTable（扩展）**——新增 `bare`（去掉 wrap 边框与默认 cell 皮肤，给已自框架的 panel 内表格用）与 `captionVisible`（可见 caption，消费者 `:deep(caption)` 自定义）。默认形态不变（既有 4 消费者零感知）。
- **BaseDropdown（删除）**——prop 驱动的死代码（grep 全仓零消费者），「复活」落地为 BaseMenu 承接键盘合同。

## 5. queryParams.ts 与 useAutoRefresh

- **src/utils/queryParams.ts（新建，src/utils 首个文件）**：queryValue/oneOf/enumQuery/uuidQuery/revisionQuery/localDateQuery/normalizeQuery 七件套。空值统一 `null`——迁移前 `''` 与 `null` 两种流派已漂移（Audit/Lark 的 `''` 流派在消费点又被 `|| null` 翻转）；表单层 `''` 哨兵由页面 `?? ''` 落回（AuditPage filterForm 十项、LarkSettingsPage recipient prop）。替换 SkillsPage/KnowledgeBasePage（逐行相同的五件套）/InboxPage/KnowledgeIndexPage/AuditPage/LarkSettingsPage/ActivityPage 七页，另收编 AppShell/ConversationPage/WorkPage 三处零散 queryValue/oneOf 副本。spec 7 条（UUID 版本位、revision ≥1、localDate 可解析、normalizeQuery 默认值删除等边界）。
- **composables/useAutoRefresh（新建）**：interval + `active()` 门禁 + visibilitychange 暂停/恢复（回前台立即刷一次）+ unmount 清理 + 可选 `maxBackoff` 退避（失败翻倍、成功复位）；**refresh 返回 false 即停**（承接 GitHub「失败即停」语义）。迁移：
  - KnowledgeIndexPage/OperationsPage 15s 双胞胎（差异仅 `refresh(true)`）：startTimer/stopTimer/onVisibilityChange/pageVisible 全删；
  - GitHubSettingsPage pollImport：1200ms setTimeout 链 + capture 守卫 → `importPolling`；**新增页面隐藏暂停**（Review 点名的债）；读失败即停语义由 `refreshImport` catch 返回 false 承接；
  - 迁移抓到并修复一个 composable 级缺陷：unmount 后**在途 tick 完成不得复活计时器**（`disposed` 终局守卫，GitHub spec 的 unmount 轮询契约测试承证）。退避能力已就位（spec 覆盖翻倍/cap/复位）但 GitHub 保持恒速失败即停——其错误处理自己吞错，强行退避要改 catch 语义，如实记录未启用。

## 7. 视觉基线

F03 快照零漂移经两轮回查达成（漂移即缺陷、不顺手 update）：

- **ObservabilityPage（m10 快照）**：迁移后 desktop 侧曾 +11px。三段式定位（像素带分析 → 真实 spec 内嵌盒探针 → 单文件 stash 新旧对照）锁定根因：BaseSelect 内建 `font-size: var(--cs-text-base)`（14px vs 消费者 label 13px）与 `width: 100%` 把角色筛选 select 撑宽（116→136px / flex 内被 shrink 到 131px），挤压兄弟文本「角色筛选」折成两行。修复=消费者 `.role-filter :deep(select)` 三覆盖 `font-size: inherit; width: auto`（连同既有 `min-height: 0`），probe 与旧版逐项全等（select 116×28/label 28/doc 1106）。**narrow 基线随之重生成**：旧基线本身 397px 宽（390px 视口横向溢出 7px——快照把 select 撑宽 bug 一并固化），修复后回归 390 视口宽，快照按修复后形态重生成（desktop 基线无此问题，维持原样）。
- **LarkNotificationAdmin（m6 快照，narrow 390×2438）**：17 条差异带（12px 小带 ×4 + 48px 带 ×7 + 11px 文字带）曾疑为表格行皮肤/滚动位移，两轮 AI 读图结论（「tab 栏多两项」「按钮变窄」「nav 滚动差」）均被盒探针证伪——同探针在基线工作树（HEAD stash src/）跑出唯一实质差异：select 水平 padding **8px→12px**。根因=该组件样式行 `input,:deep(select){…}` 编译为 `[data-v-x] select`（特异性 0,1,1）输给 BaseSelect 内建 `.base-select[data-v-y]`（0,2,0），`padding: 0 var(--cs-space-8)` 等 8 处覆盖全部失效。修复=前缀本组件根类升为 `.lark-admin :deep(select)`（0,2,1）恢复整条规则。两 project 快照 1 passed 归零。
- 全仓同族排查：grep 全部 `:deep(select)` 选择器形态，19 处带类前缀（0,2,1 胜内建）安全；唯二裸选择器 **WorkItemContentEditor**（`font-size: text-md` 与 `padding: space-8` 被内建盖掉）与 **ProjectExecutionDefaultsPanel**（`padding: 4/8`、`--border-subtle`/`.5rem` 局部皮肤被盖掉）同修为根类前缀——两处无截图基线，属快照外主动排查修复。
- audit/lark/注入/记忆四处表格 `bare` 模式逐属性保留原皮肤；下拉迁移只动行为层（键盘/aria/焦点），触发钮与弹层观感经 `:deep` 逐文件核对。

**教训（迁移 select 的级联规则）**：BaseSelect 的内建皮肤（`width:100% / min-height:38 / padding 0 12 / border-strong / radius-sm / font-size base`，特异性 0,2,0）对迁移前消费者的自定义 select 样式构成两条失配路径——① 裸 select 选择器（`select[data-v-x]`）不再命中子组件根元素（迁移时批量改 `:deep(select)` 的 40 处即此问题）；② 改成 `:deep(select)` 后若选择器无类前缀（0,1,1）仍整体输给内建。**迁移口诀：`:deep(select)` 必须带本组件类前缀，且逐属性核对与内建冲突的声明（尤其 font-size/width/padding——flex 行内 select 被撑宽会挤压兄弟文本折行）**。

## 8. 偏差登记

1. **「复活 BaseDropdown」落地为删除**：Review 的表述是「以 ActionMenu 合同为蓝本复活 BaseDropdown（或抽 BaseMenu）」。BaseDropdown 是 prop 驱动的受控弹层，承载不了六套的富内容（radio 组/表单/搜索列表）；删死代码、以 BaseMenu 承接合同是同一目标的更短路径。
2. **ObservabilityPage 币种表按 bare 逐属性保真**（本包早期曾按「皮肤统一」迁移，快照回查 11px 残差后改走 bare 路线）：`.currency-table` 皮肤行（font-size sm、cell padding 8/12、thead xs）逐属性重建原紧凑形态，m10 快照钉死零漂移——「同页两态混用是债」的判断让位于快照契约，皮肤统一留给后续有产品决策的批次。
3. **useAutoRefresh 的 15s 消费者多一个「空 tick」窗口**：原 startTimer 在 gates=false 时连计时都不开；composable 的 start() 总是排 tick、到点才评估 active()。gates 恢复由 watch 重启承接（KnowledgeIndex/Operations 的 `[online, autoRefresh]` watch），行为等价、至多多一次无 IO 的空调度。
4. **键盘验收 spec 首跑 11/12 失败，全部为用例侧数据契约/定位器迭代**（非产品缺陷）：① 账号/范围切换菜单在 rail 与 topbar 各渲染一份，按视口取**可见份**（`.locator('visible=true')`）；② ScopeSwitcher 断言按真实菜单结构重排（header「重新加载」menuitem 是首项、项目组头「创建 WorkProject」也是 menuitem，图标条目名字在 aria-label）；③ members/work-items 端点 pattern 补 `/organizations/{org}` 前缀与 `(\?|$)`（查询串会让 `$` 锚失配、列表落回 mockApi 空数组兜底）；④ 页面 goto 补 `team/project` query（deep-link 惯例，无 query 页面停在未选态不取数）；⑤ ModelOptionPicker 补 `agent-templates` mock（配置面板无模板元数据时 fail-closed 不渲染槽位；publisherType 只收 TEAM/ORGANIZATION，USER/TEAM 两次请求分别应答避免坐标双匹配）；触发钮可访问名即 label 的「主模型」（PERSONAL/TEAM 两份取 first）。
