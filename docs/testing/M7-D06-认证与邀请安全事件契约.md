## 1. 交付目标

M7-D06 为后续注册、认证、账号与邀请事务冻结安全 DomainEvent 和 Audit Schema。事件只表达已提交业务事实，身份、Scope、Actor、Correlation、Causation 与发生时间继续由统一 `DomainEventEnvelope` 承载。

本任务定义 10 个 V1 事件：

| EventType | Payload | Audit Category | Outcome |
| --- | --- | --- | --- |
| `USER_ACCOUNT_REGISTERED` | `UserAccountRegistered` | IDENTITY | SUCCEEDED |
| `AUTHENTICATION_SUCCEEDED` | `AuthenticationSucceeded` | SECURITY | SUCCEEDED |
| `AUTHENTICATION_FAILURES_AGGREGATED` | `AuthenticationFailuresAggregated` | SECURITY | FAILED |
| `ACCOUNT_TEMPORARILY_LOCKED` | `AccountTemporarilyLocked` | SECURITY | DENIED |
| `ACCOUNT_LOGGED_OUT` | `AccountLoggedOut` | SECURITY | SUCCEEDED |
| `ACCOUNT_PROFILE_CHANGED` | `AccountProfileChanged` | IDENTITY | SUCCEEDED |
| `ACCOUNT_PASSWORD_CHANGED` | `AccountPasswordChanged` | SECURITY | SUCCEEDED |
| `TEAM_INVITATION_CREATED` | `TeamInvitationCreated` | TEAM | SUCCEEDED |
| `TEAM_INVITATION_ACCEPTED` | `TeamInvitationAccepted` | TEAM | SUCCEEDED |
| `TEAM_INVITATION_REVOKED` | `TeamInvitationRevoked` | TEAM | SUCCEEDED |

全部事件使用 `SchemaVersion.V1` 与 `AuditRetentionLevel.EXTENDED`。未来字段语义或类型变化必须发布独立 SchemaVersion，当前注册表拒绝 V2 和未知坐标。

## 2. 账号与认证事实

账号注册载荷只保存 `OPEN / INVITATION / BOOTSTRAP` 来源和 `USER / OPERATOR` 平台角色。OPEN 与 INVITATION 只能创建 USER，只有 BOOTSTRAP 可以创建 OPERATOR，事件构造器关闭自助注册提权形状。

认证成功只保存规范 Provider Key、是否完成 Credential 参数升级和 SecurityVersion。认证失败使用以下固定低基数分类，不保存领域内部的账号不存在、密码不匹配、Credential 损坏或账号状态原因：

```text
INVALID_CREDENTIALS
IDENTIFIER_RATE_LIMITED
NETWORK_RATE_LIMITED
HASH_CAPACITY_EXHAUSTED
AUTHENTICATION_STORE_UNAVAILABLE
```

失败事件保存聚合次数与窗口秒数。临时锁定保存失败计数和策略时长。退出保存 `CURRENT_SESSION / ALL_SESSIONS` 范围与 SecurityVersion，不保存任何 Session ID。资料修改仅保存用户名、邮箱、展示名三个坐标是否发生变化；密码修改只保存 CredentialVersion 与 SecurityVersion。

## 3. 邀请事实

邀请创建保存目标内置角色、是否定向和过期时间；不保存目标邮箱。邀请接受保存稳定 Account ID、TeamMember ID、目标角色以及 `CREATED / ACTIVATED / REUSED` Membership 结果；这些 ID 不进入 Audit Summary。撤销保存目标角色和是否定向。

三个事件均拒绝 `TEAM_OWNER`，Team 所有权继续使用独立转移流程。任何邀请事件都没有明文 Token、Token Digest、目标邮箱或提交请求字段。

## 4. Audit 白名单

`CrewScopeAuditEventTypes` 使用 Java Record 组件生成每个 V1 Payload 的精确顶层字段白名单。Projector 遇到未知字段、未知 EventType 或未来 SchemaVersion 时失败关闭。

Audit Summary 只投影：

- 固定来源、角色、Provider、失败分类、退出范围和 Membership 结果；
- 布尔变更事实；
- 聚合计数、策略时长和单调版本。

Account/TeamMember ID、邀请过期时间及所有提交值不进入查询摘要。现有 Summary 安全门禁继续拒绝未知字段、完整邮箱、电话、URL、Bearer/API Key/Secret 形态值。

## 5. 敏感字段禁区

10 个 Payload 的 Record 组件通过精确白名单和类型扫描固定，不允许承载：

```text
password / password hash
LocalPasswordHash
Session ID / Cookie / CSRF
invitation token / InvitationTokenDigest
NormalizedEmail / LoginIdentitySubject
raw network address
raw authentication exception or reason
byte[] / char[] secret buffers
```

`credentialVersion`、`securityVersion` 与 `emailChanged` 是非秘密元数据；它们分别表达单调版本和变更布尔值，不携带 Credential 或邮箱内容。
