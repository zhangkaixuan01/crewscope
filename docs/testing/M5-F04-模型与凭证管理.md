# M5-F04 模型与凭证管理

## 交付结果

M5-F04 在 `/settings/models` 交付 Provider、模型目录与 ModelConnection 管理页。页面同时服务普通成员、Team Provider Manager 和平台管理员，并保持 USER、TEAM、ORGANIZATION 三类 Owner 的服务端权限边界：

- 当前成员始终可以管理自己的 USER Connection；
- 活动 TeamMember 可以读取当前 Team Connection 的安全投影，具有 `provider:manage` 界面权限的成员才显示 Team 管理操作，服务端继续以 `TeamPermission.PROVIDER_MANAGE` 重新授权；
- ORGANIZATION Connection 的列表、创建和管理入口只向平台管理员展示；
- Provider 与 Catalog 面向当前 Organization 用户只读展示版本、Region、Retention、Training Policy、Capability、Context、Output Token 和当前生效价格。

设置坐标使用 `/settings/models?team=<teamId>&provider=<providerKey>&ownerType=<type>&connection=<connectionId>`。Team 切换会清除旧 Connection 坐标、取消旧请求并重建按 Organization + Team 分区的缓存。未知 OwnerType、跨 Organization 和跨 Team Connection 在进入浏览器缓存前失败关闭。

## Connection 与凭证生命周期

页面接入 M5-A01 的真实公开命令：创建、验证、轮换、停用和撤销。创建根据 Owner 固化 Team ID，Provider 和 Region 只能来自服务端 ACTIVE 目录。详情展示公开 Connection ID、Owner、Provider、Region、Billing Subject 类型、Credential Version、Connection Version、生命周期、健康、稳定失败码和审计时间，不展示 Endpoint、Credential ID、Metadata、Adapter 或 Provider 原始响应。

既有 Connection 命令使用详情强 ETag、当前 Credential Version 和 `Idempotency-Key`。409/412 冲突会重新读取权威详情；成功后同时刷新详情与 Owner 列表。当前公开 API 没有 Connection activate/resume 命令，因此 SUSPENDED 状态只开放轮换和撤销，并明确展示恢复 API 尚未交付，避免伪造恢复操作。

撤销使用服务端稳定原因枚举 `OWNER_REQUESTED`、`CREDENTIAL_REVOKED`、`PROVIDER_DISABLED`、`POLICY_REVOKED`、`SECURITY_INCIDENT`，同时要求不可恢复确认。自由文本不进入撤销命令。

## Key 单向输入

API Key 只存在于 `ModelCredentialDialog` 的组件局部 `ref`，并作为栈上参数传给 Store 和 Gateway。它不进入 reactive Store、Route、Local/Session Storage、Toast、Telemetry、错误对象、Command Receipt 或可重放闭包。

创建或轮换失败时，当前打开表单保留 Key，允许用户显式重试；未修改输入的重试复用同一 Idempotency-Key。任一命令输入发生变化都会生成新的逻辑请求 Key。成功、关闭、Escape、Scope 切换或组件卸载会清空 Key。页面不提供已保存 Key、掩码 Key或复制入口。

## 健康与审计入口

健康只显示 `UNKNOWN`、`HEALTHY`、`UNHEALTHY` 和服务端稳定失败码。`AUTHENTICATION_FAILED`、`ENDPOINT_UNREACHABLE`、`TIMEOUT`、`RATE_LIMITED`、`PROVIDER_REJECTED`、`POLICY_REJECTED` 映射为安全说明；Provider 原始错误不进入 DTO 或 DOM。

命令成功后详情展示 Command Receipt 的 Correlation ID 和 Committed Version，作为后续统一审计页的安全入口。当前没有公开 Audit 查询 API，页面不生成本地审计记录，也不把 Command Receipt 冒充完整审计时间线。

## 治理 API 边界

领域层已有 AgentModelDefault、PolicyPack、Model Governance 和 Budget 引用，Agent Model Catalog 与 Preflight 也会执行默认、允许列表、区域、能力、数据、预算和配额交集。M5-A01 至 A03 尚未提供以下公开管理 API：

- Team / Organization Model Default 管理；
- Provider / Catalog Allowlist 管理；
- Budget Policy 目录和编辑；
- 模型治理策略编辑与 Audit 时间线查询。

M5-F04 将这些区域呈现为明确的“API 待交付”状态，不提供只在浏览器生效的表单。对应 API 交付后再补充可编辑闭环。

## 响应式与可访问性

桌面端使用 Provider 左侧目录、模型卡片、Owner 分组 Connection 卡片和内嵌详情；移动端使用单列布局，创建与轮换凭证使用 Bottom Sheet。密钥输入获得初始焦点，Dialog 支持 Escape、Focus Trap、关闭后焦点恢复。撤销使用独立 `alertdialog` 和显式确认。

Catalog、Connection Detail 和 Owner Connection Page 动态 Resource 均通过 reactive Map 中的代理更新，避免已挂载界面停留在 Loading。390×844 与桌面视口都没有水平溢出。
