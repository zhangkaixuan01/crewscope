# M7-F06 账号设置与会话安全

## 1. 交付结果

M7-F06 已实现正式 `/account` 和 AppShell 用户菜单。已认证用户可以查看并修改展示名称、用户名与邮箱，修改密码，退出当前设备，或撤销当前账号的全部浏览器会话。

账号页固定为 AppShell 内的设置工作区，分为个人资料、密码与安全、登录会话三个区域。桌面与移动端 AppShell 都提供账号菜单；“退出当前设备”只结束当前 Session，“退出全部设备”明确包含当前设备并要求当前密码确认。

## 2. Account Gateway 与 Store

Account Gateway 固定消费：

```text
GET   /api/v1/account
PATCH /api/v1/account
POST  /api/v1/account/password
POST  /api/v1/account/sessions/revoke
POST  /api/v1/auth/logout
```

`GET /account` 同时校验响应 Body Version 与单值强 ETag，二者不一致时拒绝建立账号事实。三个账号写请求统一携带 AuthStore 内存中的 CSRF 坐标和单值强 `If-Match`，Account Store 只保存公开资料、ETag、阶段和脱敏问题，不保存当前密码、新密码、确认密码或 Session 坐标。

Account Store 使用 Generation 与 AbortController 取消旧请求。身份失效、离开 `/account`、强制重读或新操作都会让旧代次失效，迟到响应不能回写新身份。强版本冲突保留稳定用户提示，并立即重新读取服务端权威账号事实；页面不继续展示提交前的本地猜测。

## 3. 资料与安全命令

- 只修改展示名称时不要求当前密码；
- 用户名或邮箱发生变化时，前端才提交当前密码与当前 `securityVersion`；
- 修改密码校验当前密码、新密码 12–128 Unicode code point、512 UTF-8 byte 上限、确认密码与新旧密码差异；
- 修改密码成功后全部 Session 已由服务端撤销，前端清空本地身份并进入正式登录页；
- 退出全部设备要求当前密码与 `securityVersion`，成功后同样进入正式登录页；
- 退出当前设备只调用 `/auth/logout`，不复用全部设备撤销命令，也不发送 Session ID。

当前密码和新密码只存在 Vue 组件私有内存与一次 Gateway 方法参数中。取消编辑、命令完成、命令失败、对话框关闭、路由离开或身份失效都会清理对应密码；这些字段不进入响应式 Store、URL、LocalStorage、SessionStorage、IndexedDB、Telemetry 或普通日志。

## 4. 交互、安全与可访问性

- 离线时展示明确摘要，并禁用资料、改密和会话撤销三个写入口；
- 用户名/邮箱修改只在实际变化时显示当前密码 Step-up；
- 全部设备退出使用 `aria-modal` 确认对话框，支持初始焦点、Tab/Shift+Tab 焦点陷阱、Escape 关闭和触发按钮焦点恢复；
- 当前密码错误保持在确认框内，清空密码并把焦点移到脱敏错误摘要；
- 页面进入、离线和强版本冲突都有确定焦点，不依赖视觉颜色传达状态；
- 头像没有图片依赖，使用展示名称的首个 Unicode code point；空白名称回退为 `?`；
- 桌面和 390px 均保持单一 `main` 与零横向溢出。
