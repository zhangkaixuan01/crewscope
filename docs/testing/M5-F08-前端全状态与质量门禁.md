# M5-F08：前端全状态与质量门禁

> 状态：已完成<br>
> 日期：2026-08-25<br>
> 模块：`crewscope-web`

## 目标

收口 M5 模型、Agent、Review 与 GitHub Delivery 的页面状态、响应式、键盘操作、辅助技术播报、低动效、组件工作台、视觉回归和敏感字段检查，使 M5 前端达到统一的发布完成定义。

## 状态与交互边界

- Agent 页面覆盖 Loading、Empty、Error、Forbidden、Personal、个人 Specialist、Team Agent、ACTIVE、DISABLED、ARCHIVED、当前配置、历史 Revision、Preflight、Conflict 与创建失败；
- 模型页面覆盖 Provider/Catalog/Connection 的 Loading、Empty、Error、Forbidden、ACTIVE、SUSPENDED、REVOKED、HEALTHY、UNHEALTHY、凭证创建、轮换、冲突和失败；
- Review Workbench 覆盖 Loading、Empty、Error、OPEN、IN_PROGRESS、COMPLETED、INVALIDATED、SELF_REVIEW Advisory、成员 Gate、修改轮次与离线关闭命令；
- GitHub Delivery 覆盖未批准、离线、Preflight、CURRENT、STALE、确认、取消、Push/PR 分步结果、UNKNOWN、RECONCILING、MANUAL_REVIEW、Conflict 和 Error；
- 已加载的公开事实保持可读，写操作依赖在线状态、当前权限、强版本和服务端复验，不由浏览器推导成功。

## 键盘、ARIA 与 Reduced Motion

Agent 创建、模型凭证、连接撤销、Review Gate、ActionBundle 确认和人工终结均使用模态语义、初始焦点、Escape、Tab/Shift+Tab 焦点环和关闭后触发器焦点恢复。ActionBundle 确认与人工终结只在当前最上层模态框处理键盘事件，避免穿透 Task Drawer。

Loading、恢复、成功和外部结果使用独立 `status`/`aria-live="polite"` 节点；错误、失效与冲突使用 `alert` 或 assertive StatePanel。列表和长证据本身不作为 Live Region，避免重复朗读。全局样式在 `prefers-reduced-motion: reduce` 下关闭非必要动画、Transition 与平滑滚动。

## Histoire 与视觉

组件工作台构建 8 个 Story、39 个 Variant。M5 新增 `M5AgentModelReviewDelivery.story.vue`，使用公开、安全的静态 Fixture 覆盖：

- 批准 Template 的 Agent 创建；
- 不健康模型连接与单向凭证输入；
- Review Advisory、Human Gate 与 INVALIDATED 历史；
- CURRENT ActionBundle 与离线只读交付。

Playwright 保留 Agent、Agent 创建、Agent 配置、模型、凭证、Review 和 GitHub Delivery 的 desktop Chromium 与 390×844 narrow Chromium 视觉基线。主页面与关键对话框继续纳入 Axe WCAG 2.2 AA。

## 敏感字段门禁

`scripts/check-web-sensitive-fields.mjs` 检查 M5 Agent、Model、Review、Delivery 公开 Web 契约、页面组件和全部 Story：

- 拒绝 Access Token、Credential ID、Webhook Secret、Remote URL、Worker/Lease/Fencing、原始 Provider/模型输出和 Business Key 等字段进入公开 DTO 或组件状态；
- Story 禁止构造敏感字段和疑似真实凭证值；
- API Key 只允许作为模型连接创建/轮换的单向命令输入，并额外验证其不会进入 `ModelStoreState`；
- CI Quality Job 与本地 `pnpm check:sensitive` 都执行同一门禁。
