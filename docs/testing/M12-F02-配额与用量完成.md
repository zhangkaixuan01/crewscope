# M12-F02：配额与用量完成记录

## 1. 关闭对象与非目标

本切片关闭「组织配额的可视治理」：`/settings/quota` 独立子页承接 A02 的 quota 三操作（读配置 / PUT 配置 / 读用量），趋势视图与拒绝提示让 MEMBER 看懂「为什么任务创建被拒、找谁调」。全部工作在 crewscope-web，后端零改动，无新依赖。

非目标（沿 S01 冻结）：

- 不做多组织切换 UI（跟随当前 principal 的 organizationId）；
- 不做配额告警/通知（后端无此操作）；
- 趋势不做后端多月端点（见偏差 1）；
- 不重写既有 SettingsShell 卡片体系，只加菜单项。

## 2. C1：图表基元 + quota 域 + 页面 + 接线

**图表基元**（`src/components/charts/`，手写 SVG、零动画、确定性布局）：

- `LineChart.vue`：`viewBox 0 0 640 240` `role="group"`，4 网格线 + y 刻度 + 序列 path + r3 端点 + 参考线（`stroke-dasharray` 移 SVG 属性，`--cs-warning` 描边）；图例 HTML ul（色样 + 名称，颜色非唯一信息）；**sr-only 等价数据表**（WorkGraphCanvas 先例）；单序列点数 > 200 降级可见 BaseTable；

**quota 域**（`src/domains/quota/`）：

- `types.ts`：契约镜像 + `isQuotaMonth`/`quotaMonthsBack` 纯 YYYY-MM 字符串算术（无 Date、无时区）；
- `gateway.ts`：`quota`/`usage(orgId, month|null)`（null=锚点调用不带参数）/`updateQuota`（PUT + Idempotency-Key + If-Match，body 恒显式两字段）；白名单映射 + nullable；
- `store.ts`：`configuration` 五相资源（403→forbidden 对齐 F01）；`command` 态；`usage`：`{anchorMonth, windowMonths[6], months 缓存}`——`loadUsageWindow` 1 无参 + 5 显式月并行，`loadUsageMonth` 按需且 **锚点未就绪时拒绝 dispatch**（深链未来月竞态，e2e 实证曾发出必 400 的 '2026-12'）；202 与 409 都强制重读 configuration；`createCommandGateway(gateway, {updateQuota: 3})`；
- `labels.ts` + `presentation.ts`：`quotaProblem`（422/409/428）与三图表数据构建器（limit null → 无参考线）。

**页面**（`QuotaSettingsPage.vue`）：三卡——配置卡（dl + 行内编辑，`useDirtyForm` + `createFormCommandKeys().forInput`，空输入=null=清除维度，保存按钮 `aria-describedby="quota-save-reason"`）、当月用量卡（month-nav URL `?month=` 驱动，watch 是唯一加载路径；metric-grid + Token 构成 BaseTable + 口径说明）、趋势卡（6 月窗口两 LineChart + 当月 BarChart）。

**权限矩阵**：MEMBER（无 org 角色）全页静态 forbidden **不发请求**（避 403 sink）；ORG_AUDITOR 只读；ORG_ADMIN/OWNER 可编辑；纯 ORG 用户可达（路由无 requiredPermission）。

**接线**：router（`/settings/quota`，`queryWhitelist:['month']`）、main.ts（install + sessionBoundary reset）、SettingsShell（organization 后插「配额与用量」）、commandInventory owners `'quota'`、menu-walk（`/quota` + `/quota/usage` 两条显式 mock）、check-config-form-tokens。

## 3. C2：拒绝提示接入 + 误伤修复

**呈现链**：task store `createErrorDetails`（`{...error.envelope.details}`，6 处清空点）与 `createErrorCode` → `quotaAdmissionProblem(action)`（`domains/quota/presentation.ts`：两英文常量逐字登记，注明 Java `OrganizationQuotaAdmissionService.java:19-23` 来源）→ `DelegateToAgentDialog` 的 `createErrorCopy` computed（命中→中文指引含「组织设置 → 配额与用量」；未命中→透传原文）。未知 action 永远保留原文，不吞错。

**C2 调试发现并修复的真实缺陷**：WorkPage `taskForbidden` 原先把 `createErrorStatus` 计入页面级禁止——任务创建 403（含 quota policy_denied）会整页跳 access-denied，把对话框与中文指引一起弹掉。配额拒绝是业务答复而非权限撤销。修复：`quotaAdjustedCreateErrorStatus` computed（403 且 `createErrorCode === 'policy_denied'` 且 action 命中已知常量 → 不计 forbidden）；其余 403（如 PlatformRoleAuthorities 的真权限问题）行为不变。

**e2e**：A05 fixtures 加 `createDenial`（可插拔 403 policy_denied 线缆形态）；delegation 新用例断言中文指引可见、英文常量不出现在 UI、无 task 副作用。

## 4. 偏差声明（8 条）

1. **趋势无后端端点**：前端以无参 usage 响应为锚点，往回 5 月显式 GET 拼合 6 月窗口（有缓存、请求有界）；参考线是**当前**配额投影，非历史值。
2. **月份锚点服务端单源**：缺省月=服务端报表月；前端零本地时区推断；深链未来月在锚点未就绪时拒绝 dispatch、就绪后回退锚点（不发必 400 的请求）。
3. **PUT 缺省=清除的线级行为**：前端恒显式携带两字段（空输入→null），不依赖服务端缺省合并语义。
4. **reserved/actual 两口径并列不归因**：预占（承诺口径，≥实际、终态不退款）与实际（org+月 rollup，统计延迟）在页面并列展示 + 口径说明，不做对账（A02 契约承接）。
5. **403 sink 规避**：MEMBER 档前端 `can()` gate 静态渲染 forbidden、不发请求；forbidden 相位仅覆盖服务端撤销竞态。
6. **mock 403 钉死文案**：C2 e2e 以 fixture 注入 403 policy_denied 线缆形态，两英文常量与 Java 常量逐字对齐（A02 偏差声明 2 承接）。
7. **契约 doc §5 的 400 表述 vs 实测 422**：本切片按 422 `invalid_value` 消费；契约文档 `docs/api/M12-配额与用量API契约.md` §2/§5 已顺手修正为 422。
8. **client 层 403 sink 未按 policy_denied 豁免**（已知限制）：quota 拒绝的 403 同样触发 `main.ts` 全局 `onForbidden → clearF05TeamScope`，清掉当前 Team 的 F05 本地草稿（权限并未撤销）。影响仅本地草稿丢失、无跳转（WorkPage 豁免已修）。后续切片可在 client 按 `envelope.code + details.action` 精确豁免；本切片不动 client 全局语义。
