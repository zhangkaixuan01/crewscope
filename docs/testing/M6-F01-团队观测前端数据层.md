# M6-F01 团队观测前端数据层

## 1. 交付结果

M6-F01 为后续 Activity、Inbox、Audit、飞书通知与 Operations 页面建立统一前端数据边界：

- `domains/teamops/types.ts` 定义浏览器公开 DTO、Cursor Page、强版本详情和固定命令结果；
- `domains/teamops/gateway.ts` 对接 M6-A01 至 A04、A06 的真实 API，并通过显式 Mapper 重建 Activity、Inbox、Audit、Lark/Notification 与 Operations 响应；
- `domains/teamops/store.ts` 提供 Organization + Team Scope 缓存、请求取消、Scope Generation、请求身份、Cursor 分页、精准失效和稳定命令状态；
- `domains/teamops/errors.ts` 把 Offline、Forbidden、Cursor Expired、Conflict、Unavailable 与 Invalid Response 转换为稳定 UI 错误；
- `domains/realtime/cursorStore.ts` 生产化 Team Event、Conversation Event 与 AG-UI 三流恢复存储；
- 应用组合根安装 `HttpTeamOpsGateway` 与 `TeamOpsStore`，F02 至 F07 可以直接消费。

## 2. Scope、请求与分页

Store 的 Scope Key 同时包含 Organization 与 Team。切换 Scope 会中止全部在途请求、递增 Generation、清空查询/命令缓存和资源 Cursor。每个响应写入前同时校验 Request Key、请求身份、Scope Key 与 Generation；即使测试 Gateway 忽略 `AbortSignal`，旧 Team 的晚到响应也不能进入新 Team 状态。

Activity、Inbox、Audit、成员映射与 Notification Delivery 分别保存服务端不透明 Cursor。加载更多只消费当前资源 Cursor，重叠项按公开稳定 ID 去重。服务端返回 `410 cursor_expired` 时清除当前 Continuation Cursor 并保留稳定 `cursor-expired` 错误，后续页面执行 Snapshot 或首屏回读。

## 3. 强版本与秘密边界

Inbox、Lark Connection、Notification Preference 和 Notification Delivery 详情要求 HTTP Header 强 ETag 与公开 Body Version 完全一致；Inbox 同时对账 Body `etag`。命令只使用已加载详情 ETag，冲突把服务端 `currentVersion` 保存为稳定错误事实并等待页面显式回读。

App Secret、精确 `open_id`、Idempotency-Key、危险 Projection 命令 Body 与确认参数只存在于表单局部状态和单次 Gateway 调用栈。它们不进入 Reactive Store、Cursor Storage、URL、Command State 或自动重试闭包。Gateway 返回的未知字段、Credential Handle、Provider Body 和内部 Projection 坐标由公开 Mapper 丢弃。

## 4. 三流恢复

- `TEAM` 保存 Team Event 耐久 Cursor，键绑定 Organization + Team；
- `CONVERSATION` 保存 Conversation Event 耐久 Cursor，额外绑定 Conversation；
- `AG_UI` 只保存 `invocationId + idempotencyKey + eventOffset`，不把 SSE `id` 写成耐久 Cursor；
- LocalStorage 解析或形状校验失败时立即删除损坏条目；
- `clearScope` 只删除精确 Organization + Team 下的三流坐标，不影响其他 Team。

恢复存储不接受 Credential、Prompt、Secret、Provider Payload 或任意业务正文。

## 5. 验证

专项测试：

- `gateway.spec.ts`：DTO 白名单、Activity/Operations 内部字段丢弃、Inbox 三方强 ETag 对账、飞书 Secret 单向请求、Audit 固定路径与媒体类型；
- `store.spec.ts`：旧 Team 晚到响应、Gateway 忽略取消、Cursor 重叠去重、410 过期、秘密不缓存、强 ETag 命令和 409 当前版本；
- `cursorStore.spec.ts`：Team/Conversation Scope 隔离、AG-UI 非耐久 Cursor、损坏存储清理和 Conversation Identity 约束。
