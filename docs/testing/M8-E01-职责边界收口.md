# M8-E01 职责边界收口

## 本轮边界

Operations API 的命令身份推导已从 `OperationsController` 抽出到 `OperationsCommandIdentity`。Controller 只负责路由、权限解析、请求装配和响应映射；命令命名空间、Organization 隔离和幂等键规范由独立组件维护。

Projection/Recovery 请求的值对象解析、版本校验和稳定 `invalid_request` 映射已抽出到 `OperationsRequestParser`，避免 Controller 直接承载领域构造和异常细节。

Notification Intent Projection 的 JSON 解析和序列化已抽出到 `NotificationProjectionJsonCodec`。Codec 只处理受限变量、Inbox 类型、可信 Origin 和固定能力声明；Projection 保留 JDBC 查询、授权决策、幂等写入和投影生命周期。

Review Persistence 的 JSON 序列化、字符串数组和 Evidence 坐标读取已抽出到 `ReviewPersistenceJsonCodec`。Repository Adapter 保留 SQL、事务和领域对象持久化，不再直接承担 JSON 结构校验。

AgentScope Task Runtime 的失败分类与时长预算失败构造已抽出到 `AgentScopeFailureClassifier` 和 `TaskDurationBudgetException`。Runtime 只负责 AgentScope 事件编排、生命周期和执行状态；Classifier 统一处理超时、运行时事件拒绝和模型不可用三类稳定合同，保留重试语义与公开错误码。日志仅记录异常类型链和可选 HTTP 状态，不记录 Prompt、Provider 原文、Token、Endpoint 或 Secret，避免把供应商细节穿透到应用边界。

Task Agent 的受控 Prompt 生成已抽出到 `AgentScopeTaskPromptFactory`。该 Factory 只接收已授权的运行时事实和 segment 类型，负责将 Task Brief 作为不可信数据分区、生成固定计划模板和恢复提示；Runtime 不再同时承担 Prompt 文本策略，后续可独立对 Prompt 合同做字符边界和工具序列测试。

Task Tool 的 allowlist、名称边界和当前 Step 授权校验已抽出到 `AgentScopeTaskToolPolicy`。Runtime 只调用策略组件，不再直接拼接工具授权规则；未知工具、控制字符和越界 Fixture Tool 均 fail-closed。

执行状态索引键已抽出到 `AgentScopeExecutionKey`。该值对象只由 TaskExecution、AgentScope userId 和 sessionId 构成，并在构造时执行长度与控制字符校验；Runtime 的并发 Map 不再同时承担租户坐标解析和输入清洗。

AgentScope Task 的可变执行状态已抽出到 `AgentScopeTaskExecutionState`。该组件独立维护 Lease/Owner 重绑定、Segment 生命周期、控制幂等、Resume fencing、Token 计数、Terminal 事件序列和挂起工具；Runtime 只持有按 `AgentScopeExecutionKey` 索引的状态 Map，并负责把 AgentScope 事件路由给状态组件。

该组件只接受不透明 `Idempotency-Key`，使用固定命名空间和 Organization 坐标派生稳定 UUID，不读取请求体中的敏感内容，也不改变已有 HTTP、事件或数据库合同。后续 Notification Projection、Review Persistence 和 AgentScope Runtime 的拆分沿用同一原则：编排层不直接承担 SQL、DTO 映射和运行时状态管理。

## Contract Test

- 同一 Organization 与同一幂等键得到相同命令 ID；
- 不同幂等键得到不同 ID；
- Recovery 与 Projection 命名空间隔离；
- Controller 继续使用现有公开 endpoint 和响应类型。
- 非法字段统一映射为 `invalid_request`，不传播领域异常原文。
- Codec 对变量名和数组结构执行 allowlist 与边界校验，未知字段 fail-closed。
- Review Evidence 坐标必须是对象数组，字符串数组拒绝非字符串元素。
- AgentScope 超出时长预算映射为 `TIMEOUT/DURATION_BUDGET_EXCEEDED` 且可重试；不安全事件映射为不可重试的 `AUTHORIZATION/TASK_RUNTIME_EVENT_REJECTED`；其余模型调用失败统一映射为可重试的 `MODEL_UNAVAILABLE/TASK_MODEL_FAILED`，不传播异常原文。
- Prompt Factory 对首次规划、已发布计划续跑和单 Step 执行分别生成固定模式；Task Brief 继续经过边界转义，恢复模式不会重新生成规划模板。
- Task Tool Policy 对允许工具做 trim、长度和控制字符校验，工具调用必须同时通过运行时 allowlist、Task Token scope 和当前 Plan Step 声明。
- ExecutionKey 对同一执行与 Session 槽位保持稳定相等关系，非法坐标在进入并发状态索引前被拒绝。
- ExecutionState 在 Owner epoch 变化、重复控制、Resume fencing、Terminal 重复和安全检查点场景下保持原有状态合同；事件序列和 UTC 时间仍由显式 Clock 驱动。
