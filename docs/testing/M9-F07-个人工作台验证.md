# M9-F07 个人工作台验证

## 交付范围

`/`（`pages/TodayPage.vue`）按 spec 重建为个人工作台，接入 `GET /organizations/{organizationId}/teams/{teamId}/work-desk`，使用 Team 作用域与当前成员身份：

- **需要我行动**：等我决策的 Human Gate、待我 Review、被我阻塞三区合并呈现，来自全部 WorkProject；三项都空时**收起**并给正向空状态（`StatePanel` 的 `action` 插槽给出当前权限下真的可以走的下一步）。
- **我的工作**：看板，按**责任角色**或**按状态**分组可切换（分组方式与筛选一起写进 URL，刷新与分享可复原）；卡片显示状态、进度、责任角色、阻塞标记与最近更新时间。支持**就地改状态**（复用 `StatusTransitionMenu`，与 `/work` 是同一份服务端裁决）与**拖拽**（复用 `composables/useBoardDrag.ts`）。
- **正在执行**：进行中的执行条目、状态与最近更新时间，点进去直达 Execution Studio。
- **今日动态**：今天有更新的工作项与执行，按最近更新排序；今天没有更新时如实说明并给出最近一次更新的相对时间。
- **ScopeSwitcher 降级为过滤器**：首页不再要求先选范围，项目筛选只是收窄看板。
- **Setup 未就绪时顶部引导条**（`.setup-strip`，不占整页）；首次加载用 `BaseSkeleton` 而不是整页空白。
- WorkDesk 网关对响应字段、作用域、进度、角色与站内路由做白名单校验，拒绝外部或路径穿越地址。

## 两处如实记录的偏差

1. **按责任角色分组时看板不可拖拽**。把卡片放到某个角色列意味着「改派责任」，那是另一条命令（`M9-F09` 的批量指派命令面），不是状态流转；在角色分组下开启拖拽会造出一个看起来能改派、实际执行不了的手势。因此拖拽只在「按状态」分组下开启，并在界面上说明原因（`desk-board--locked` + 明文的 `aria-describedby`），切回按状态即可拖动。
2. **首页不呈现执行的「实时阶段与耗时、异常高亮」**。工作台投影的 `WorkDeskItem` 只有 `status` / `progress` / `urgency` / `updatedAt` / `responsibilityRole` / `availableActions` / `route`，没有阶段与耗时字段；「正在执行」给出条目、状态与最近更新时间，阶段与耗时在 Execution Studio 的 Task 详情里（那里有 Runtime 事实与 Attempt 历史）。要对齐计划文本就得往投影里加字段，那是后端契约变更，不属于本工作包，本轮不做也不假装做到。

| 用例 | 场景 |
|---|---|
| `shows personal workdesk and keeps filters in the URL` | 单项目成员；筛选进 URL |

| `aggregates every WorkProject and narrows the board with the project filter` | 跨 5 个项目聚合 + 项目过滤 |
| `keeps a member without participation permission read-only and says why` | 无权限成员：只读并说明原因 |
| `executes a card action through the work item Store and re-reads the projection` | 就地改状态走 Store 命令路径并回读投影 |
| `moves a card between status columns with the keyboard alone` | 键盘拖拽（`Space` → 方向键 → `Enter`） |

## 运行时验收

1. 登录并进入 `/`，Team 就绪后即可看到个人工作台，不要求先进入 WorkProject。
2. 切换分组方式、项目、责任角色或「仅看需要我行动」，URL 查询参数同步变化且请求下推到 WorkDesk API。
3. 在看板上就地推进一个工作项（点徽章或拖拽），确认成功后出现撤销入口，且 `/work` 中同一条目状态一致。
4. 点击「正在执行」或「今日动态」中的条目，确认落到对应详情且能继续进入 Execution Studio。
5. 无数据时给出可执行的下一步；服务不可达时显示离线/错误态与刷新入口；Team 未就绪时顶部出现引导条而不是整页跳转。

四类场景的浏览器验证使用 mock 的服务端响应；真实后端的闭环属 `M9-Q02`。
