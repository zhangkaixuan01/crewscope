# M9-F07 个人工作台验证

## 交付范围

- Today 页接入 `GET /organizations/{organizationId}/teams/{teamId}/work-desk`，使用 Team 作用域与当前成员身份。
- 首页展示“需要我行动”“我的工作”“正在执行”“Inbox”四类派生内容，条目直接使用服务端返回的稳定 `route` 跳转。
- 支持 WorkProject、责任角色（负责人/执行人/Reviewer）和“仅看需要我行动”筛选，筛选状态写入 URL，可分享、刷新后保留。
- 保留 WorkProject 创建、Setup Center、Work、Conversation 与团队成员快捷入口。
- WorkDesk 网关对响应字段、作用域、进度、角色和站内路由做白名单校验，拒绝外部或路径穿越地址。

## 运行时验收

1. 登录并进入 `/today`，Team 就绪后可看到个人工作台，不要求先进入 WorkProject。
2. 切换项目、责任角色或“仅看需要我行动”，URL 查询参数同步变化且请求下推到 WorkDesk API。
3. 点击任一条目，使用 API 返回的稳定站内 route 进入 Work、Review 或 Inbox 详情。
4. 无数据时显示可执行的“进入 Work”下一步；服务不可达时显示离线/错误状态与刷新入口。
5. 通过创建 WorkProject 与 Setup Center 快捷入口，确认原有范围管理能力保持可用。
