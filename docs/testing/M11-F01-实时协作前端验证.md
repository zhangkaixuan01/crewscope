## 3. 方案说明与实现注意

1. **默认 e2e 的惰性通道**(`vite.config.ts` `inertCollaborationChannelPlugin`):模拟后端没有协作 WS,真实代理会把升级转发给 8080 的模拟栈外端口,连接失败三次(~3.5s)即把 store 打进 degraded——609 项既有测试的页面会集体长出降级 UI,既有基线全部失守。惰性插件由 `playwright.config.ts` webServer 的 `CREWSCOPE_E2E_DEV=1` 标记启用:完成 101 升级握手但永不发帧,store 停在 connecting(connecting 不渲染任何协作 UI),协作面对默认层完全沉默;`testIgnore '**/m11-real/**'` 把真实栈 spec 排除在默认层之外。
2. **routeWebSocket 视觉方案**(`app-shell.spec.ts` M11 测试):`page.route` 不能 mock WS 升级,而一个会失败的升级会把 store 打进 degraded。Playwright 1.62 的 `page.routeWebSocket` 在浏览器网络层拦截(先于 vite 惰性插件),单测试内驱动**真实 store** 走 welcome→subscribed→presence_delta/typing/resource_changed,让三面渲染 live 状态进入视觉与 axe 门禁;mock 的 `typingWindowSeconds: 600` 保证截图窗口内 typing 指示不自清。该测试之外的一切保持惰性沉默,pre-F01 基线形状不变。
3. **useVirtualList 视口收缩贴底修复**(首跑失败定位):collaboration strip(min-height 26px)在初始 scroll-to-bottom **之后**挂载,收缩 message-history 视口——`containerObserver` 旧逻辑只对非跟随者 `restoreAnchor`,跟随者(FOLLOW_THRESHOLD=80 内)距底 26px 无人重贴底,破坏「距底 <4px」的阅读位置不变量。修复:containerObserver 增加跟随分支 `scrollTop = scrollHeight` 重贴底;大于 80px 的收缩由 `readMetrics` 翻转 isFollowing 走锚点路径,与既有布局位移语义一致。单测用 FakeResizeObserver stub 触发回调覆盖该分支(`useVirtualList.spec.ts` 第 11 例;jsdom 无 ResizeObserver,stub 仅在该测试内生效)。
4. **真实栈双账号 spec**(`collaboration-presence.spec.ts`):m7 邀请链路建 Bob(MEMBER,含 WORK_PARTICIPATE 可 REST PATCH);bob 先被 REST 加为 conversation 参与者(composer 可用性依赖参与者投影);PATCH 带 CSRF + `Idempotency-Key` + `If-Match: "V"` 断言 202,版本动态读取。连接复用语义:同 spec 内跨页面一个 WS(引用计数归零不关连接)。
5. **降级栈 UI 断言**(`collaboration-degraded.spec.ts` 第三测试):降级态的断言用 hidden→visible 两段式,避免把陈旧状态误判为重试成功。
6. **真实栈镜像必须晚于 A01 的 welcome 扩展**(首跑失败的根因):I01c 时代的旧 api 镜像在 welcome 帧里只带 4 个传输层字段(`connectionId/heartbeatIntervalSeconds/inboundIdleTimeoutSeconds/presenceTtlSeconds`),缺 A01 契约 §1 的 `principalId/typingWindowSeconds/maxInboundSignalsPerSecond`。store 的入站帧守卫对不满足契约形状的帧静默丢弃,于是通道开着、ping/pong 正常、welcome 却永远不被消费——store 停在 connecting(不渲染任何 UI、也永不 degraded,因为连接没断),三面全部静默。诊断探针(临时 `probe-ws.spec.ts`,已删):`page.on('websocket')` 抓帧确认「welcome 已到、无 subscribe 发出」。修复=重建 api 镜像后全绿;这同时验证了「连接挂起 vs 显式失败」的降级语义边界——只有连接**失败**才走三连败→degraded,挂起的旧形状连接不在其列(契约外的帧形状是未定义行为,静默丢弃是当前选择)。
