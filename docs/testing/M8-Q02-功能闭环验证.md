## 3. 本轮修复

GitHub.com 的 Installation Token 没有可用的独立 `/installation` 身份资源，真实验证应使用 `/installation/repositories` 的仓库 Owner 投影。适配器现在兼容两种形态：旧兼容网关继续使用 `/installation`，GitHub.com 404 时回退到 Installation Repository Catalog，并继续以 Connection 外部账号、Allowlist、Catalog 和 Preflight 进行约束校验。

Installation Token 返回的仓库对象可能将用户级 `pull/push` 权限显示为全 `false`；对已通过 Team App Connection 验证的安装，适配器按 App 的最小交付能力处理该投影，实际仓库访问仍由 Catalog 与 Preflight 请求再次校验。
