# M4-F08：前端全状态与质量门禁

> 状态：已完成<br>
> 日期：2026-08-20<br>
> 模块：`crewscope-web`

## 目标

收口 Repository Settings 与 Execution Studio 的产品状态、响应式、键盘操作、辅助技术播报、低动效、视觉回归和组件工作台，使 M4 Coding 前端达到统一的页面完成定义。

## 页面状态

Repository Settings 保留已经成功加载的 RepositoryBinding 事实。浏览器离线后，列表继续可读，绑定、Preflight、启停和刷新统一关闭；恢复联网后由成员显式继续操作。绑定面板打开后聚焦 Repository 下拉框，Escape 关闭并把焦点交还给当前 DOM 中的原触发按钮。Catalog 加载引发按钮重建时，焦点恢复使用稳定触发器标识重新定位节点。

Repository 创建候选使用 AVAILABLE Catalog 与当前 Binding Key 的差集。已绑定仓库继续显示在事实列表，不再进入新建下拉框；创建成功和列表刷新都会重新计算可绑定数量。

Execution Studio 统一覆盖 Ready、Recovering、Terminal、Offline、Loading、非 Coding Empty 和 Error。当前 attempt 的执行控制同步状态使用 Live Region；Repository Preflight、Coding 状态刷新和 Artifact 分页错误分别使用适合的 `status` 或 `alert` 语义。动态状态只播报公开业务事实。

## 响应式、动效与视觉

- 桌面视口验证 Repository Settings 与 Execution Studio 的信息密度、双栏关系和操作区；
- 390×844 窄屏验证 Repository 卡片、执行阶段、Diff、Evidence 和控制区的顺序阅读；
- CodingTarget 加载动画在 `prefers-reduced-motion: reduce` 下关闭旋转；
- 页面延续浅色、低饱和的团队协作工作台语言，以状态文字、图标和局部底色共同表达结果；
- 视觉基线独立保存 Repository Settings 与 Execution Studio 的桌面和窄屏截图。

## 安全与可访问性门禁

- Repository、Execution Studio、Diff、Evidence 和 Coding Progress 纳入桌面与窄屏 Playwright 回归；
- Repository Settings 纳入全局 Axe WCAG 2.2 AA 页面集；
- 键盘覆盖面板初始焦点、Escape 关闭和触发器焦点恢复；
- 离线测试在 `finally` 中恢复 BrowserContext 网络，避免污染同一 Worker 的后续用例；
- Artifact 403 只从当前 Task/attempt 的 Patch、Command Log 与 Test Report 资源计算，历史缓存不能改变后续 Task 的权限导航；
- 浏览器状态不包含宿主路径、容器坐标、Token、Lease/Fencing、AgentState、State Reference、Checkpoint Hash 或 reasoning。

## 收口审查

- Repository 创建候选只保留 AVAILABLE Catalog 与当前 Binding Key 的差集；Catalog 未就绪或刷新失败时关闭新建、Draft Preflight 和提交；
- Diff SSE 对相对路径、变更类型、非负安全整数、布尔值和 64 位十六进制 Hash 执行浏览器白名单校验，非法嵌套列表交由 Gap 与权威快照收敛；
- 单文件 Patch 只按精确 `diff --git` Header 定位，正文、`+++` 和 Rename 文本不能伪造文件边界；
- Artifact 权限状态按当前 Task 与 attempt 隔离，历史缓存不能污染当前 Execution Studio；
- Artifact 下载文件名移除路径段，并拒绝空值、`.`、`..`、控制字符和超过 255 字符的名称；
- Repository Catalog 基础设施依赖执行非空校验，文件系统读取异常统一映射为路径无关的 `503 repository_catalog_unavailable`，原始 cause 只保留给可信日志。
