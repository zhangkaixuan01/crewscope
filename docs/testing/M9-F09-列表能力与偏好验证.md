# M9-F09：列表能力与偏好验证

## 交付范围

本任务建立所有列表页共用的四项基础能力：

- `useListSort` 统一排序键、方向切换与服务端查询参数，带允许键白名单；
- `useSelection` 支持跨游标页保留选择、当页全选、上限与部分页面回显；
- `formatRelativeTime` / `formatAbsoluteTime` 统一相对时间和完整时间提示，未来时间不会出现负数；
- `usePreference` 作为唯一的 `localStorage` 入口，使用版本化载荷、损坏值回退和跨标签页同步。

`AppBreadcrumb` 从路由 `meta` 派生并接入 `AppShell`，所有页面均有稳定的上下文位置。

## 验证结果

- `useListSort.spec.ts`：允许键、升降序切换、重置与非法键拒绝；
- `useSelection.spec.ts`：跨页选择、上限和当前页回显；
- `usePreference.spec.ts`：版本不匹配回退、持久化、跨标签页同步与重置；
- `formatRelativeTime.spec.ts`：刚刚、分钟、小时、未来时间和非法输入边界；
- Activity 与 Inbox 列表使用相对时间，并以完整绝对时间作为悬浮信息；
- AppShell 全页面接入面包屑。
- `m6-activity` 与 `m6-inbox` 的 Desktop/Narrow Darwin 视觉基线已按预期变化重拍，10 条对应 E2E 全部通过。

排序、批量命令与服务端游标查询的业务动作由后续工作台任务接入；本任务不改变既有领域 API、事件或权限语义。
