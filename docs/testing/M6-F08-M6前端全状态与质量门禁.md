# M6-F08 M6 前端全状态与质量门禁

> 完成日期：2026-08-27
> 范围：`crewscope-web` 的 Activity、Inbox、Audit、Lark/Notification、Team Observer 与 Operations

## 1. 交付结果

M6 六个工作台已使用同一页面完成标准收口：全状态可表达，已有公开事实在离线、续页过期和刷新失败时保持可读，所有不成立的分页、证据、外部动作和管理命令失败关闭。Desktop 与 Narrow 复用同一语义 DOM，并通过键盘、ARIA、Reduced Motion、视觉和 Axe 门禁。

本任务及提交前整体 Review 修复六个产品缺口：

- Activity 在离线缓存态仍可触发“加载更早活动”，现已按在线性禁用；
- Operations 初始健康错误和管理员诊断错误使用了错误的 StatePanel 事件，现已提供可用的“刷新事实”动作；
- 普通资源强制刷新失败会清空上一次成功值，现已保留最近公开事实并进入 Cached Error；
- 统一命令槽可被第二个并发命令覆盖，现已在 Store 层对 Pending 期间的新命令失败关闭；
- Team Observer 的 Cancel、Summary 与 Evidence 请求缺少完整的 Scope Generation 和业务坐标守卫，现已在切换 Scope 或 Invocation 后取消并丢弃全部晚到结果；
- Conversation 切入 Team Observer 未推进页面同步代次，现已在清空 Personal Conversation 状态前使旧异步链失效。

Review 同时修正文档章节归属：Team Observer 的身份、响应式和离线规则归入其双入口章节，组件工作台顺延为 9.10。

## 2. 状态与恢复矩阵

| 工作台 | 固化状态 | 离线约束 |
|---|---|---|
| Activity | Live、Reconnecting、Loading、Empty、Forbidden、Offline、CursorExpired、Cached Error、WorkItem Embedded | 已加载事件可读；续页关闭；联网后按 Team Cursor 恢复 |
| Inbox | Ready、Detail、Detail Loading/Error、Conflict、Count Error、Loading、Empty、Forbidden、Offline、CursorExpired、Cached Error | 列表与详情可读；处置、来源解析和续页关闭 |
| Audit | Ready、Detail、Correlation Ready/Loading/Error、Loading、Empty、Forbidden、Offline、CursorExpired、Export Success/Error | 审计事实可读；导出、Correlation 续页和列表续页关闭 |
| Lark/Notification | Connection、Mapping、Notification、Failed Detail、三资源 Loading/Error、Empty、Forbidden、Offline、CursorExpired、Conflict | 公开连接、映射与投递可读；Credential、Mapping、Preference 和 Redelivery 命令关闭 |
| Team Observer | Conversation、Control、Running、Reconnecting、Completed、Cancelled、Retryable Error、Empty、Offline Cached | 摘要可读；Invoke、Resume、Refresh 与 Evidence 跳转关闭 |
| Operations | Member、Administrator、Loading、Initial Error、Diagnostics Error、Empty Projection、Empty Recovery、Conflict、Offline Cached | 健康与诊断可读；自动刷新暂停；Projection 与 Recovery 命令关闭 |

Team Event、Conversation Event 与 AG-UI 继续使用三个独立恢复命名空间：前两者保存 Scope-bound 耐久 Cursor，AG-UI 保存 `invocationId + idempotencyKey + eventOffset`。损坏坐标会被删除，Conversation/AG-UI 缺少 Conversation Scope 时失败关闭，AG-UI SSE ID 不能被当作耐久 Cursor。

所有 M6 查询 Store 还执行两级晚到防护：AbortController 负责尽快释放旧传输，Scope Generation 与精确资源坐标负责拒绝无法取消的旧响应。刷新错误不删除最近成功值；页面必须显式表达该值为缓存事实，并继续关闭依赖新鲜授权或版本的命令。

## 3. 可访问性与响应式

- StatePanel 使用 `status/alert`、`aria-live`、`aria-atomic` 与 `aria-busy`；
- Credential 与 Operations 强确认对话框具备 `aria-modal`、初始焦点、Tab/Shift+Tab 环、Escape、Pending 禁止关闭和焦点恢复；
- Observer 模型摘要始终作为纯文本，证据跳转每次重新授权；
- Desktop Chromium 使用 `1440×960`，Narrow Chromium 使用 `390×844`；
- Playwright Context 固定 `reducedMotion: reduce`，StatePanel 与 Operations 旋转动画在 Reduced Motion 下关闭；
- 六个工作台的代表页面执行 Axe，视觉基线在两个视口保持稳定。
