# M9-F10：配置体验重构验证记录

## 目标

验证九类配置面共享同一套可读、可恢复、可审计的交互基线，同时保持配置语义、权限、校验和不可变 Revision 模型不变。

## 已落地能力

- `useDirtyForm()` 统一跟踪脏态，支持路由离开、浏览器刷新和对话框关闭确认；Team Scope 切换自动保存本地草稿。
- `FormField`、`SettingsShell`、`ModelOptionPicker`、`RevisionDiffView` 提供统一表单、导航、模型选择和版本差异呈现。
- Agent 配置数值输入显示 `min`、`max`、`step` 与字段级错误文案，输入框使用至少 14px 正文，标签和辅助文案使用至少 12px。
- Revision Hash 完整展示并可复制；版本差异只读、逐字段展开嵌套对象，不提供覆盖历史版本的写入口。
- 模型选择按 Provider 分组并支持键盘搜索，选项同时展示区域、归属、能力和价格。
- API Key 复用 `AuthPasswordField`，明文切换默认关闭，提交边界 `trim()`；过期时间限制为当前时刻之后。
- 模型治理页展示服务端生效事实，不再显示“API 待交付”占位卡片。

## 验证命令

```bash
pnpm --dir crewscope-web test -- --run
pnpm --dir crewscope-web build
node scripts/check-web-sensitive-fields.mjs
git diff --check
```

专项单元测试覆盖 `useDirtyForm` 的脏态/草稿/刷新保护，以及 `RevisionDiffView` 的嵌套字段差异和无差异版本。

## 安全边界

本任务未新增配置字段、写接口或权限；历史版本只读。草稿仅保存在当前浏览器 Scope，API Key 不写入草稿、URL、日志、Toast 或遥测。
