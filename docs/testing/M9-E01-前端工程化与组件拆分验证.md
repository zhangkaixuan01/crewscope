# M9-E01 前端工程化与组件拆分验证

## 交付范围

- 接入 ESLint 9、`eslint-plugin-vue`、`@typescript-eslint` 与 Stylelint 16。
- `crewscope-web/package.json` 增加 `lint:eslint`、`lint:style` 与统一 `check:quality` 门禁。
- 将 `WorkPage.vue` 的新建 WorkItem 表单提取为 `WorkItemCreateDialog.vue`，容器页面只负责生成项目内 Key、调用 Store 和处理路由/业务结果。
- 对话框负责表单状态、字段校验、输入清洗、键盘焦点陷阱、Esc 关闭与提交事件，保持原有服务端接口和错误边界。

## 验证结果

在仓库根目录执行：

```bash
pnpm --dir crewscope-web check:quality
pnpm --dir crewscope-web test -- --run
pnpm --dir crewscope-web build
node scripts/check-doc-links.mjs
git diff --check
```

结果：

- ESLint、Stylelint、Web 质量检查通过；
- Vitest：135 个文件、721 个测试通过（包含 `WorkItemCreateDialog.spec.ts`）；
- Vite 生产构建通过；
- 文档链接检查与 Git 空白检查通过。

## 拆分边界

本阶段采用增量拆分。`WorkPage.vue` 仍保留工作项列表、看板、任务与执行工作台的业务编排；后续可按同一模式继续提取 `ConversationPage.vue`、`AgentConfigurationPanel.vue` 与 `TaskDetailDrawer.vue`。不通过一次性重写改变既有交互或领域接口。
