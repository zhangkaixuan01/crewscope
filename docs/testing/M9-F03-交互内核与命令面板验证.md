# M9-F03：交互内核与命令面板验证

## 交付范围

- `src/app/actionRegistry.ts` 提供前端单例 `ActionRegistry`，统一声明动作的标签、分组、关键词、图标、权限、快捷键和执行函数，并提供重复注册、权限过滤与快捷键冲突检查。
- `src/app/shortcuts.ts` 提供全局快捷键管理器：`⌘K`/`Ctrl+K` 唤起命令面板，`?` 唤起帮助，支持 `g` 导航、`c` 创建、`v` 视图、`x` 执行控制序列，序列超时 250ms。
- `src/components/action/CommandPalette.vue` 提供 Teleport 对话框、动作搜索、A02 对象搜索、最近访问、分组结果、权限不足/加载中/离线/无结果状态，以及方向键、Enter、Escape 和鼠标操作。
- `main.ts` 注册默认导航、创建、视图和执行控制动作；AppShell 顶栏搜索入口改为打开命令面板，统一搜索仍可从注册动作进入。

## 快捷键约定

| 快捷键 | 行为 |
|---|---|
| `⌘K` / `Ctrl+K` | 打开命令面板 |
| `?` | 打开快捷键帮助 |
| `g t/c/w/i/o/m/a/s/e/d/r/x/f` | 今日、对话、工作、Inbox、团队观测、成员、审计、配置、Agent、模型、仓库、运行、搜索 |
| `c c` / `c w` | 发起对话、进入工作项创建入口 |
| `v t/c/w` | 切换今日、对话、工作视图 |
| `x o` | 打开执行控制 |

## 验证结果

- ActionRegistry 注册、重复快捷键冲突检测、权限过滤：通过。
- `Cmd/Ctrl+K` 打开命令面板并执行高亮动作：通过。
- 两键序列、250ms 超时及输入框禁用：通过。
- 中文输入法组合输入通过 `event.isComposing` 与键码 229 防误触发；Dialog、Drawer、Textarea、Select 和可编辑区域由目标边界守卫禁用全局快捷键。
- 命令面板通过 `role="dialog"`、`aria-modal="true"` 与 `useFocusTrap()` 保证键盘可达，Escape 关闭并归还焦点。
- 交互内核接入 AppShell 后，顶栏模式切换、面包屑和侧栏布局的预期尺寸变化已在 macOS Chromium 的桌面与窄屏基线中重拍；未放宽像素差异阈值，所有 156 个 AppShell E2E 用例通过。

本任务未新增领域 API、数据库迁移或后端 Action；前端动作可见性不构成授权边界，实际业务命令仍由服务端复验。
