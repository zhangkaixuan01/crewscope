# M12-F03：企业身份与会话完成记录

## 1. 关闭对象与非目标

本切片关闭「M12-I01 企业身份与会话契约的前端消费面」：LoginPage 的 OIDC 登录入口与策略面（登录回跳失败提示、sso-only 救援）、AccountPage 的活跃会话列表与单会话撤销、账号的登录方式（身份源）展示。全部工作在 crewscope-web，后端零改动，无新依赖；消费 [企业身份与会话 API 契约](../api/M12-企业身份与会话API契约.md)（I01 交付，OpenAPI 303→305）。

非目标（沿 I01 契约与 §6 :124 边界）：

- **不做身份源策略配置页**（见偏差 1）：`identityPolicy` 是部署级配置（SecurityMode 三态派生），I01 契约只读无 PUT 面；前端以策略提示文案+登录方式列表呈现；
- 前端不保存 IdP 密钥、不接 OIDC 协议细节——SSO 入口是框架全页导航（`/oauth2/authorization/{registrationId}`），授权码流全部在后端；
- 不重复组织管理：身份源列表挂在账号页（本人视角），组织级身份治理归 F01/A01 面；
- SAML、SCIM、MFA 是 I01/F03 下的独立可选子范围，不在本切片。

## 2. C1：identity 数据层 + LoginPage 策略面（提交 e2d496b）

**数据层**（`src/domains/identity/`）：

- `types.ts`：契约镜像——`identityPolicies`（local-only/sso-only/coexist）、`loginIdentityStatuses`（ACTIVE/DISABLED/REVOKED）两词汇；`AuthSession` 增 `identityPolicy`/`ssoAuthorizationUrl`（匿名对称：有注册时匿名与认证态都可能非空）；`AuthSessionAccount` 增 `loginIdentities`（provider/status/lastAuthenticatedAt，无 subject——契约不回显）；`BrowserSessionSummary`（**置文件尾 RegistrationResult 之后**：M7 敏感字段门禁扫描 `LoginCredentials` 之前段禁 sessionId 字段名，会话摘要属 owner 会话管理面非匿名安全投影）；
- `gateway.ts`：`sessions()`（GET /auth/sessions，`{sessions:[...]}` 信封）与 `deleteSession(sessionId, csrf, signal)`（DELETE 204，非 204 抛 TypeError 走既有错误通道）；mapSession/mapAccount 白名单扩展；`identityPolicyLabel`（三态部署提示文案）；
- `presentation.ts`：`presentLoginProblem` 增 `local_login_disabled`（sso-only 部署本地登录 403 的中文指引）；新增 `presentSsoReturnProblem(code)`——后端回跳 `?sso_error=` 固定四码 denied/locked/registration_blocked/unavailable 的本地化标题+正文，**未知值折叠进 denied 兜底，原始 query 永不进 DOM**（不回显 subject/claims）。

**LoginPage**：

- 入口：`ssoAuthorizationUrl` 非空渲染 `data-testid="login-sso-entry"` 锚点（Building2 图标，「使用企业单点登录进入」，真实 `href` 全页导航）；coexist 时 divider「或使用账号密码」+本地表单并存；
- sso-only：本地表单不渲染（`passwordFormVisible = formVisible && !ssoOnly`）、注册 footer 隐藏、救援文案「无法完成单点登录？请联系你的管理员恢复访问。」替代；
- 回跳：onMounted 读 `route.query.sso_error`，出横幅后 `router.replace` 清除 query——刷新或分享链接不重放横幅；`focus-on-mount` 让位于横幅（有 ssoProblem/auto-focus 时不抢焦点）；
- 既有九个 identity 相关 spec 的 fixture 补齐三新字段（gateway mock 增 sessions/deleteSession）。

**单测**：`m12-oidc-login.spec.ts` 10 用例——coexist 双入口并存、无 OIDC 保持 M11 形态、sso-only 隐藏表单+救援、四码 it.each 断言+query 清除、unknown sso_error（`%3Cscript%3E` 不回显）、local_login_disabled 文案、`presentSsoReturnProblem` 纯函数全枚举。

## 4. 偏差声明（6 条）

1. **身份源策略配置页 → 展示**：计划 §6 :124 交付列「身份源策略配置页」，但 I01 契约将 identityPolicy 定为部署配置（SecurityMode 派生、只读），无 PUT 操作；本切片以登录页策略提示文案+账号页登录方式列表替代配置页。若后续需要运行时可调策略，须先有后端契约变更。
2. **sso_error 四码在浏览器层抽样验证**：vitest 全枚举四码+unknown；Playwright 只走两码+hostile 值（管线事实：query→横幅→URL 清除→不回显），避免同管线四倍重复。
3. **当前会话撤销的登出是本地完成**：DELETE 204 后不再发 /auth/logout（会话已亡），直接 `signOutLocally()` 清前端态并路由 /login——与「删当前=登出等效」的 I01 语义一致。
4. **404 提示与刷新的顺序耦合**：loadSessions 入口无条件清 sessionsProblem，404 折叠文案必须在刷新完成后设置（实现以 owner.isCurrent() 守卫）；单测钉死「提示可见且列表已刷新」双断言。
5. **C1 契约扩展的 e2e fixture 连锁**：`mapSession` 白名单新增三字段后，16 个 Playwright fixture（auth-session.ts 共享夹具+15 个自带 session 形态的 spec/fixtures）与 menu-walk 兜底缺字段会抛 TypeError——本切片随 e2e 一并补齐；menu-walk 增 `/auth/sessions → {sessions:[]}` 显式形状（通用 `s$` fallback 的 items 信封会被 sessions 映射器拒绝）。
6. **会话删除全局互斥**：`deletingSessionId` 非空时所有行按钮禁用（单飞 DELETE，避免连点双删其一 404）；与既有账号命令通道互不干扰。
