# M9-A02：统一搜索验证记录

## 已交付

- 新增 `SearchQueryService`、`SearchIndexPort` 与成员权限委托，统一以 Organization/Team/Member 作为查询边界。
- 新增 PostgreSQL 派生查询 Adapter，覆盖 WorkItem、Conversation、Task、RepositoryBinding、Agent、TeamMember 六类对象。
- 新增 `V38__unified_search_indexes.sql`，启用 `pg_trgm` 并为可检索文本建立 GIN 索引。
- 新增带版本的不透明 keyset cursor 与严格请求参数校验。
- Web 端新增 `/search` 页面、对象类型筛选、站内跳转、游标加载更多、加载/空/错误/离线状态，并接入 AppShell 顶栏搜索入口。

## 验证结果

- `./mvnw test -DskipTests`：通过（Domain、Application、AgentScope、Integration、Infrastructure、Server 全模块编译）。
- `pnpm test`：通过（703 tests）。
- `pnpm build`：通过（vue-tsc 与 Vite production build）。
- `git diff --check`：提交前执行；迁移文件不得包含 EOF 空白行。

## 安全与边界

- 查询始终复用 `WorkItemAccessPolicy` 的 Team 成员权限；切换 Team 后旧响应被丢弃。
- `%`、`_`、`!` 在 SQL ILIKE 查询中转义，cursor 采用版本化 Base64URL 编码。
- 前端拒绝外部、协议相对、路径穿越和含空白的服务端 route。
- 搜索结果只返回稳定标题、状态、时间和站内 route，不回传凭证、Endpoint、宿主路径或 Provider 原文。
