# M2-F06 前端状态与可访问性硬化

## 交付范围

- 统一 Loading、Empty、Error、Offline、Reconnecting 和 Cancelled 状态组件；
- AppShell 提供全局离线提示和“跳到主要内容”入口；
- 离线时保留已加载事实和 Composer 草稿，允许继续编辑，只禁止提交；
- Conversation 状态使用独立 ARIA Live Region，Message 历史不重复朗读；
- 选中对话、窄屏返回、新建弹窗和创建成功具有明确焦点转移与恢复；
- 弹窗支持初始焦点、Tab 焦点陷阱、Escape 关闭和触发元素恢复；
- 全局支持 Reduced Motion；
- 窄屏 Composer 支持 16px 输入、安全区、紧凑高度和大触控按钮；
- State Story 补充 Offline、Reconnecting 和 Cancelled 变体。

## 事实边界

`navigator.onLine` 只用于网络交互提示。服务端请求、授权结果和领域 API 响应继续是业务事实来源。页面不会在重新联网时自动发送草稿，不会把断网视为 Agent 取消，不会生成本地 Conversation、Message 或 WorkItem 事实。

## 自动化验证

- Vitest 覆盖网络状态监听启停、离线/重连/取消语义和 Composer 离线草稿契约；
- Playwright 在桌面与 390px 窄屏覆盖离线草稿、恢复联网、详情聚焦、返回恢复、弹窗焦点陷阱和 Reduced Motion；
- 原有断线重放、刷新恢复、显式取消和安全公开流场景继续通过；
- Axe 覆盖 Conversation、Today、Work、Team Members 和 WorkItem Detail；
- 桌面与窄屏浅绿色视觉基线通过。
- 路由离开后清理 Conversation/Message 内存快照，重新进入时回读服务端当前事实。

验证结果：

- Vitest：30 个测试文件、119 个测试全部通过；
- 前端覆盖率：Statements 87.51%、Branches 83.01%、Functions 85.82%、Lines 88.86%；
- TypeScript 检查和 Vite 生产构建通过；
- Histoire：5 个 Stories、20 个 Variants 构建通过；
- Playwright：桌面与窄屏共 72 个场景全部通过；
- WCAG 2.2 AA 自动检查和浅绿色视觉回归通过。
