# M0-E01：统一事件契约

> 状态：已完成<br>
> 日期：2026-08-06<br>
> 涉及模块：`crewscope-domain`、`crewscope-application`

## 目标

建立 DomainEvent 事实信封和 AG-UI、Conversation、Team 共用的实时事件信封，固定 SchemaVersion、JSON 表示和向后读取规则，为 M0-D06 的同事务持久化及 M0-E02/E03 的发布投影提供稳定输入。

## 领域契约

`DomainEvent` 是业务 Payload 标记接口。`DomainEventEnvelope<T>` 统一保存：

```text
eventId, eventType, schemaVersion,
organizationId, teamId?, workspaceId?,
aggregateType, aggregateId, aggregateVersion,
actorType, actorId?,
correlationId, causationId?, idempotencyKey?,
occurredAt, payload
```

`RealtimeEventEnvelope<T>` 统一保存：

```text
eventId, domainEventId?, streamType,
eventType, schemaVersion,
aggregateType?, aggregateId?, aggregateVersion?,
correlationId, causationId?, occurredAt, payload
```

持久 DomainEvent 投影到多个实时流时保留 `domainEventId`、`aggregateVersion` 和 `correlationId`，并为每条流事件生成独立 `eventId`。AG-UI 瞬时事件的 DomainEvent 和 Aggregate 坐标为空。

## JSON 契约

- 使用 camelCase 字段；
- Envelope 字段顺序固定；
- 可选字段固定写出为值或 `null`；
- 读取缺失或为 `null` 的可选字段；
- 忽略未知 Envelope 字段；
- Envelope 根节点和 Payload 使用 JSON Object；
- UUID 使用 canonical 非 Nil 表示；
- SchemaVersion 使用正十进制字符串；
- aggregateVersion 使用非负 64 位整数；
- 时间使用 UTC RFC 3339 文本并保持 PostgreSQL 微秒精度。

Codec 位于 application 层，使用 Spring Boot 4 依赖管理的 `tools.jackson.core:jackson-databind` 3.x。领域模块不依赖 Jackson、Spring、JPA 或数据库实现。

## 数据库承接

V1/V2 的 `domain_event.subject_type` 和 `subject_id` 对应 Envelope 的 `aggregateType` 和 `aggregateId`。V3 新增 `aggregate_version` 并实现领域状态、DomainEvent 和 Outbox 的同事务写入。V1/V2 迁移保持不变。
