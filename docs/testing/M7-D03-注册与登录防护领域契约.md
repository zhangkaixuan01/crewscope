# M7-D03 注册与登录防护领域契约

> 任务：`M7-D03`<br>
> 日期：2026-08-28<br>
> 状态：完成<br>
> 关联决策：[ADR-025](../adr/ADR-025-本地密码与登录防护参数.md)

## 1. 交付目标

M7-D03 将 S03 实测安全参数落为领域与应用契约：

- `RegistrationMode` 固定 `OPEN / INVITE_ONLY / DISABLED` 三种本地账号创建模式；
- `PasswordPolicy` 实施 code point/UTF-8 双预算、常见密码拒绝集和非法 Unicode 拒绝；
- `LoginAttemptPolicy` 冻结标识/网络窗口、Account 失败窗口、临时锁定、Hash 等待与 Retry-After；
- `AccountLoginAttemptState` 以有界、时间单调的不变值表达已知 Account 失败与临时锁定；
- `AuthenticationFailureMapper` 把内部认证原因折叠为不可枚举的公开结果。

## 2. 注册与密码

Registration Mode 行为：

| Mode | 无邀请 | 已验证邀请 |
| --- | --- | --- |
| `OPEN` | 允许 | 允许 |
| `INVITE_ONLY` | 拒绝 | 允许 |
| `DISABLED` | 拒绝 | 拒绝 |

邀请布尔值只表示已经上游完整验证的邀请，不接受“客户端声称有 Token”作为信任事实。

注册和改密必须同时满足 12–128 个 Unicode code point 且 UTF-8 不超过 512 byte，并通过本地固定常见密码拒绝集。登录不使用最小长度和常见值规则，只在 Account 查找和昂贵 Hash 前执行 128 code point/512 byte 最大预算，保证历史短密码输入仍进入一次真实或 Dummy Match。

PasswordPolicy 只返回固定结果枚举，不保存提交值。常见值比较只使用 Locale-independent 小写副本，交给 PasswordEncoder 的值保持原始 code point 序列，不 trim、不改大小写、不做 NFC/NFKC。

## 3. 登录窗口与临时锁定

标准策略：

```text
identifier        = 10 attempts / 15 minutes
controlled network = 60 attempts / 5 minutes
known account      = 10 failures / 15 minutes -> lock 15 minutes
hash admission     = wait 100 ms
capacity retry     = Retry-After 1 second
```

`AccountLoginAttemptState` 不保存 Account ID、标识、网络地址、密码、Hash 或内部错误。失败时间按升序保存且最多为阈值 10；窗口下界时刻的失败已过期，第 10 个当前窗口失败建立精确 15 分钟锁定。锁定期间的请求仍由后续 I03 执行 Dummy Match，但不再增长 Account 失败集。

锁定到期边界清窗口；未锁定时成功认证清 Account 失败窗口，不清标识或网络资源限流。反向时间、乱序/未来失败、超阈值窗口、达阈值却无锁定、无阈值证据却有锁定或锁定超过 15 分钟都失败关闭。

临时锁定是 I04 Redis 防护状态，不转换持久 `UserAccount.status`。持久 `LOCKED` 继续表达账号安全/管理状态；两者都不可认证并对匿名调用方隐藏区别。

## 4. 公开失败折叠

以下原因返回完全相同的 `invalid_credentials`：

```text
password input rejected
unknown account
account locked / disabled / archived
identity disabled / revoked
credential missing / malformed
password mismatch
temporary login lock
```

identifier/network 限流和 Hash Permit 溢出返回相同的 `too_many_requests + Retry-After: 1`。`SafeAuthenticationFailure` 不持有内部 Reason、Account、Identifier、Subject 或 Password 字段，且构造器拒绝非固定 code/message/retry 组合，防止上层改成枚举性文案。
