# CrewScope 前端术语表

M13b-F12（S6/S13）建立。本表是前端文案的唯一词源：新文案先查表，表里没有的先补表再写代码。

## 术语契约（S13 裁决）

1. **中文为主**：面向用户的字段名、表头、按钮、提示一律中文。技术标识（ID、SHA、版本号、
   API 路径）保留原文并以 mono 字体展示。
2. **枚举必经词表**：面向用户的枚举值一律经 `src/domains/**/labels.ts` 映射成中文；原始枚举
   常量只在「技术详情」折叠区（如导出校验和 details）出现。开放词表（如 eventType）类型为
   `Record<string, string>`，未登记值经 `enumLabel` 回退原常量——新事件落地时在词表补一行。
3. **同一概念一个叫法**：本表「中文叫法」列是唯一标准；出现同义改写（如「成员/用户/参与者」
   指同一物）时以本表为准收敛。
4. **专名保留英文**：下表「保留英文」列的词不翻译（生态专名或协议词），但首次出现的页面要
   有中文语境（标题、说明里带中文）。

## 状态与枚举词表索引

全部在 `crewscope-web/src/domains/` 下，改动词表须同步跑 `pnpm check:enum-labels`：

- `teamops/labels.ts`：activity 事件类型（`activityEventTypeLabels`，开放词表）、类别、
  操作者类型、关联对象类型、引用类型、审计类别/结果/保留级别、Correlation 来源、
  实时相位（`activityRealtimePhaseLabels`）、恢复候选类型等。
- `principal/labels.ts`：平台角色（`platformRoleLabels`）。
- `shared/labels.ts`：`enumLabel`/`enumLabelOr` 唯一入口——helper 不拥有文案。
