## 3. 保持不变的设计

- AgentScope 2.0.0 Spike 使用确定性 Model、固定 Docker 镜像 Digest 和临时 Git 仓库；
- 领域层保持纯 Java，应用层声明 Port，JPA 与 Flyway 位于基础设施层；
- JPA Entity 使用标量 UUID，不建立隐式跨租户 ORM 关联；
- WorkItem 使用 `CANCELLED` 表达取消，不增加通用逻辑删除字段；
- V1 是已存在的历史迁移，本次只修改尚未形成发布基线的 V2；
- WebFlux 调用 JPA/JDBC 的有界阻塞调度、统一 API 错误信封和数据库唯一冲突映射按 M0-A01/A02 实施。

## 4. 提交门槛

完成修正后必须满足：

1. 领域、应用、迁移和 Repository 定向测试通过；

3. V1 校验和不变；
4. `git diff --check` 通过；
5. Testcontainers 与 AgentScope Sandbox 无残留容器。
