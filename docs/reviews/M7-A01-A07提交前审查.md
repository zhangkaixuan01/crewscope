## 1. 审查结论

M7-A01 至 M7-A07 的分层与装配边界成立。Application Service 保持纯 Java，Spring 使用显式 Bean 和构造器注入；WebFlux 的 PostgreSQL 路径离开 Event Loop；密码、Hash、Session ID、Cookie、Token Digest 与内部异常不进入公开 DTO、事件、Audit 或错误信封。

注册在事务外执行 Argon2id，在同一事务内提交账号链、邀请接受、DomainEvent、Outbox 和 Receipt，提交后才建立 Session。改密和全会话撤销先推进数据库 SecurityVersion，Redis 删除失败不会使旧 Session 继续通过当前事实复核。邀请 Accept/撤销统一使用 Invitation→Team 行锁顺序，明文 Token 只在首次创建结果出现。

## 3. 保留的设计决策

- Registration Request Hash 不保存密码；完成重放必须对当前 Credential 执行一次密码复验；
- 邀请创建重放只恢复 Receipt，不恢复一次性明文 Token；
- Current Account 只提供当前账号资料、改密和账号级 Session 撤销，不提供可枚举其他账号的查询；
- 公开 DTO 在 M7 入口内逐类失败关闭，不全局改变 M0–M6 已发布 DTO 的 Jackson 未知字段语义；
- Team Beta API 只通过覆盖 Forwarded Header 的 Nginx 和内部 Backend Network 可达，应用使用 Framework Forwarded Header 规范化。
