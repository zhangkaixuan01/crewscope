## 3. 审查后保持不变

- ResponsibilityAssignment 创建即生效，释放后保留历史且不复活；
- Owner 只通过原子替换变更，Assignment ID + Version 防止 ABA 覆盖；
- Gate Reviewer 必须是 Active TeamMember，默认与直接 USER Owner/Executor 分离；
- Agent Executor 所有者与委托链的扩展职责分离继续由后续 Policy Engine 和 PolicySnapshot 实现；
- 单人团队降级必须携带 PolicyPack ID、版本和原因；
- Specialist Agent Reviewer 只有 Advisory 效力；
- V5 Team 不虚构 Owner，`owner_member_id/default_workspace_id` 继续允许成对为空；
- Comment 和 ResourceLink 保持不可变事实，M1 不提前实现 HTTP API、DomainEvent、AuditEvent 或前端。
