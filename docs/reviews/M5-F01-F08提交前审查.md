## 3. 审查后保持不变

- Agent 与 Model Gateway 只接受和返回公开字段，Credential Secret 不进入响应、缓存、日志、Story 或测试快照；
- Store 使用完整 Scope、请求代次与 AbortSignal 隔离切换前后的请求，晚到响应不能污染新 Scope；
- 写命令使用强 ETag、Idempotency-Key 和冲突回读，浏览器不自行生成服务端授权、PolicySnapshot 或计费事实；
- Task Delegation 固定 Preflight 返回的精确 Configuration Revision，Retry 明确区分沿用父配置和主动切换；
- Review 展示精确 Context、Diff、Test、Acceptance 与 Finding 证据，Agent Advisory Finding 不能替代成员 Gate Decision；
- GitHub Delivery 以完整 ActionBundle Digest 进行 Owner Confirmation，Push、Draft PR、Receipt 与 ExternalResult 分步展示和对账；
- `UNKNOWN`、过期 Lease 与 `RECONCILING` 通过查询恢复、对账或人工队列收敛，不在浏览器侧推导成功或自动重放；
- 页面同时支持对话式入口和传统管理入口，桌面与 390×844 窄视口共享同一业务事实。
